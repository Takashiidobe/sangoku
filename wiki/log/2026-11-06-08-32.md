# Add SM83 documentation to asm-lsp

_2026-11-06 08:32:05_

Bookkeeping, tooling. The RGBDS server tried earlier could not give instruction
hover or timings for the Game Boy CPU, so I extended `asm-lsp` instead.

Extended `~/asm-lsp` with a separate `sm83` architecture using the Z80 XML
documentation format and shared summaries. Added a generator pinned to
`gbdev/gb-opcodes` data, covering 500 opcode forms and 14 SM83 registers with
corrected Game Boy syntax and T-cycle timings. Added embedded instruction and
register artifacts, schema and config-builder support, architecture-aware
hover/signature rendering, and tests excluding Z80-only features. Installed the
local release build at `~/.cargo/bin/asm-lsp`. Switched sangoku `.asm-lsp.toml`,
the Codex LSP config and the executable-gated Neovim block to `asm-lsp`.

All 146 workspace tests passed; Clippy, formatting, Python checks and headless
Neovim hover/completion/signature checks passed. RGBDS directives and inlay
hints remain outside this change.
