## Files and implementation

`third_party/rustc_codegen_cranelift/Cargo.toml` changes all Cranelift crates
from sibling paths to the shared fork branch; Cargo.lock records the resolved
commit.

```diff
-cranelift-codegen = { path = "../wasmtime/cranelift/codegen", ... }
+cranelift-codegen = { git = "https://github.com/Takashiidobe/wasmtime.git",
+    branch = "gbc-lr35902", ... }
```

Keeping all crates on one branch avoids mixing API revisions. The repository is
named `wasmtime`, but this is the project's Cranelift fork.
