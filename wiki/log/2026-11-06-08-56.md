# Extract a reusable Python emulator helper

Added tests/emu.py with an Emulator class for the SM83 instruction subset used
by runtime tests. Registers and flat 64 KiB memory are directly accessible.
step() returns an instruction's CPU clock cost; run_until() returns elapsed CPU
clocks with an instruction limit; cycles tracks the accumulated total.
Unsupported opcodes fail explicitly. No full GBC hardware or bus timing claim.

Moved multiplication execution onto the shared helper. RET now pops a real
return address; tests verify restored SP and the untouched stacked argument.
Implemented flag behavior for supported instructions, signed SP offsets, address
wrapping, and memory operands. Added independent helper regressions. README
describes the interface and timing units. No Bead created, as requested.

Validation: all 13 Python tests pass, including 10,256 multiplication pairs and
five timing cases. Ruff checks/format, cargo clippy --allow-dirty --fix, cargo
fmt, and git diff --check pass. Runtime and compiler sources unchanged.
