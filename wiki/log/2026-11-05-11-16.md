## Files and implementation

`cranelift/codegen/src/isa/lr35902/inst/mod.rs` changes frame-relative slot
calculation so local spills sit after the outgoing-argument area:

```diff
-StackAMode::Slot(offset) | StackAMode::OutgoingArg(offset) => offset as i32,
+StackAMode::Slot(offset) => offset as i32
+    + frame.map_or(0, |frame| frame.outgoing_args_size as i32),
+StackAMode::OutgoingArg(offset) => offset as i32,
```

The call setup reserves outgoing argument space. Without this adjustment, a
local spill could overlap an argument being prepared for the callee.
