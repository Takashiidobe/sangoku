# Native-width bit scans and reversal (sangoku-mt4.9, .1, .2)

_2026-11-08 15:55_

## Context

`sangoku-mt4.9` (epic) continued the bounded runtime cleanup: implement native
`i8`/`i16`/`i32` CLZ, CTZ and bit reversal with independently selected
size/speed variants and shared byte kernels, wired into Cranelift. This is not
an exhaustive SDCC comparison or byte-value sweep.

## Case

`leading_zeros`, `trailing_zeros` and `reverse_bits` on `i8`/`i16`/`i32`.

## Currently emits

Narrow-to-`i32` widening, CTZ marker insertion, CLZ padding subtraction and
reversed-high-byte extraction. The listing is not recorded.

## Should emit

Six native narrow libcalls with typed signatures and both symbol mappings; the
fix-ups above are removed and zero scans return their native width.

```text
operation  width  size/speed linked bytes  size/speed zero T-cycles
CLZ/CTZ    8      11/52                    336/44
CLZ/CTZ    16     15/69                    792/72
CLZ/CTZ    32     25/99                    2104/144
reversal   8      15/29                    272/132
reversal   16     20/34                    556/276
reversal   32     38/52                    1184/624
```

Cycles are helper entry through `RET`, excluding caller packing/`CALL`/spills.
Zero `i32` scan improves from 2104 to 144, but short scans can favor compact:
CLZ top-bit or CTZ one costs 104 compact versus 108 speed cycles. Reversal
timing is input-independent. Public registers/flags are caller-saved; nested
byte calls need at most two extra stack bytes, compact scans none.

## How

All public entries use the established register ABI and signed/unsigned bits.
Size scans use bounded whole-word shifts; speed skips empty bytes and calls an
unrolled nonzero-byte kernel, tail-jumping for the first selected byte. Private
kernels take/return `A` and do not bundle a public `i8` wrapper. Compact and
speed reversal share an A-to-A byte kernel preserving `B`/`C`/`D`/`E`: speed
uses nibble/pair swaps and masks, size a rotate loop. No tables or scratch RAM;
required byte kernels are included in the byte counts and retained once.

Tests: zero, all ones, every single-bit position and three mixed patterns, plus
tiny `no_core` Rust at `0`/`z` for all native operations (signed results, full
`u32` count returns, live inputs); SP/arguments and no non-stack writes checked.
20 focused tests pass in 1.45 seconds including existing popcount/CLZ coverage;
all 36 LR35902 backend tests pass. Registry checks cover all six levels,
required byte dependencies and shared selection, with no unrelated widths
retained. Pinned release backend rebuilt; clippy `--allow-dirty --fix`, fmt, LSP
and diff checks pass. Reproduce:
`cargo nextest run --no-fail-fast -E 'binary(bitops)'`.

## Alternatives

No Rust fork, core or full application ROM rebuild was needed; no exhaustive
byte sweep or broad SDCC comparison.
