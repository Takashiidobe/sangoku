# Native-width bit scans and reversal

sangoku-mt4.9 and .1/.2: Continue the session's bounded runtime implementation
workflow. Add and hook size/speed CLZ, CTZ and bit reversal for i8/i16/i32.
This is not an exhaustive SDCC comparison or byte-value sweep.

Add six native narrow libcalls, typed signatures and both symbol mappings.
Remove narrow-to-i32 widening, CTZ marker insertion, CLZ padding subtraction
and reversed-high-byte extraction. Zero scans return their native width.
All public entries use the established register ABI and signed/unsigned bits.

| Operation | Width | Size/speed linked bytes | Size/speed zero T-cycles |
| --------- | ----- | ----------------------- | ------------------------ |
| CLZ/CTZ   | 8     | 11/52                   | 336/44                   |
| CLZ/CTZ   | 16    | 15/69                   | 792/72                   |
| CLZ/CTZ   | 32    | 25/99                   | 2104/144                 |
| reversal  | 8     | 15/29                   | 272/132                  |
| reversal  | 16    | 20/34                   | 556/276                  |
| reversal  | 32    | 38/52                   | 1184/624                 |

Size scans use bounded whole-word shifts. Speed skips empty bytes and calls
an unrolled nonzero-byte kernel, tail-jumping for the first selected byte.
Private kernels take/return A and do not bundle a public i8 wrapper. Compact
and speed reversal share an A-to-A byte kernel preserving B/C/D/E; speed uses
nibble/pair swaps and masks, size uses a rotate loop. No tables/scratch RAM.
Required byte kernels are included in the linked byte counts and retained once.

Helper entry-through-RET cycles exclude caller packing/CALL/spills. Zero i32
scan improves from 2104 to 144, but short scans can favor compact: CLZ top-bit
or CTZ one costs 104 compact versus 108 speed cycles. Reversal timing is
input-independent. Public registers/flags are caller-saved. Nested byte calls
need at most two additional stack bytes; compact scans allocate none.

Validation: zero, all ones, every single-bit position and three mixed patterns,
plus tiny no_core Rust at 0/z for all native operations, signed results, full
u32 count returns and live inputs. SP/arguments and no non-stack writes checked.
20 focused tests pass in 1.45 seconds, including existing popcount/CLZ coverage.
All 36 LR35902 backend tests pass. Registry checks all six optimization levels,
required byte dependencies and shared selection; no unrelated widths retained.
Pinned release backend rebuilt; clippy --allow-dirty --fix, fmt, LSP and diff
checks pass. No Rust fork, core or full application ROM rebuild was needed.
Reproduce: cargo nextest run --no-fail-fast -E 'binary(bitops)'.
