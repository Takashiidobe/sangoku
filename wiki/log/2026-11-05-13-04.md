## Files and implementation

`src/driver/mod.rs` identifies floating-point MIR on the target;
`src/driver/aot.rs` skips such routines from `core` and compiler-builtins but
reports a fatal error for user crates:

```diff
+if has_lr35902_float_mir(tcx, mono_item) {
+    if is_compiler_builtins || tcx.crate_name(LOCAL_CRATE) == "core" {
+        continue;
+    }
+    tcx.sess.span_fatal(span, "floating-point operations are not supported on LR35902");
+}
```

The helper checks monomorphized local declaration types and only activates for
`Arch::Other("z80")`. This lets integer-only `core` progress without silently
accepting float use in games. It is a deliberate omission strategy instead of
adding software float operations and runtime helpers.
