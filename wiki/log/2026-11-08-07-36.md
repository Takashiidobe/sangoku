# Split fast and extensive nextest profiles (sangoku-ddo)

_2026-11-08 07:36:42_

Routine nextest runs were slow, so sangoku-ddo (P2) added `.config/nextest.toml`
with a fast default profile and a full `extensive` profile. Default selects 151
tests; extensive selects all 171 original tests. Moved 11 originally reported
slow tests/targets plus 9 more observed above 10 seconds in validation;
FileCheck stays in default. The filter uses exact test/binary names, so future

> 10s cases, except FileCheck, must be added to it.

Updated README and AGENTS commands/policy, targeted wiki commands, and the
post-fork-rebuild recommendation so expensive checks explicitly select
`extensive`.

Validation: nextest JSON listings compared with the original inventory (full
extensive selection unchanged; all observed >10s non-FileCheck tests excluded
from default). Initial default (160 tests) took 49.371s; refined default (151)
took 11.051s: 150 passed, 1 unrelated sort-example ROM-capacity failure (54314
bytes, limit 32768). FileCheck took 10.746s, the only final test above 10s.
Extensive was validated by listing, without another full run. Clippy, fmt,
`bash -n tools/rust_fork.sh` and diff checks pass. Pre-existing
`Cargo.toml`/`Cargo.lock` and `examples/heap.rs`/`examples/sort.rs` edits stay
outside this commit. No push.
