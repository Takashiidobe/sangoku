## Files and implementation

`cranelift/codegen/src/isa/lr35902/inst/emit.rs` emits the Game Boy restart
opcode for a trap, while `inst/mod.rs` formats it as `rst $10`:

```diff
+Inst::Trap => sink.put1(0xD7),
...
+Inst::Trap => "rst $10".into(),
```

`lower.rs` maps Cranelift traps to this instruction. The ROM owns the vector at
`$10`; current startup code disables interrupts and loops there. A dedicated
target vector is valid LR35902 code, unlike host trap opcodes or a fake
unreachable instruction.

Commit: `ede96e8a` — Cranelift (`third_party/wasmtime`). Purpose: Give trap
paths generated by compiler/core code a target-specific terminal behavior.
Change: Lower Cranelift traps to the LR35902 `RST $10` vector. Implementation:
Added a trap machine instruction and emitted the restart opcode through the
existing target instruction path; ROM startup owns the vector behavior.
Alternative: A host trap opcode or unreachable placeholder is not valid Game Boy
code; the dedicated vector provides a stable target hook.
