## Files and implementation

`cranelift/object/src/backend.rs` adds a builder for callers that use
`ObjectModule` but emit assembly rather than serialize a native object:

```diff
+pub fn new_for_assembly<V: Into<Vec<u8>>>(
+    isa: OwnedTargetIsa,
+    name: V,
+    libcall_names: Box<dyn Fn(ir::LibCall) -> String + Send + Sync>,
+) -> ModuleResult<Self> {
+    binary_format: object::BinaryFormat::Elf,
+    architecture: object::Architecture::Unknown,
+    flags: object::FileFlags::None,
+}
```

The builder keeps Cranelift's symbol/function management and module interfaces
while RGBDS owns assembly and final linking. This avoids inventing a parallel
function-registration layer just for text output.
