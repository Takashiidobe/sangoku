# Select audited memcmp runtime implementations

sangoku-mt4.11: Promote the independently written size/opt candidates from
wiki/log/2026-11-08-12-05.md into runtime/memory/memcmp/{size,speed}/pointer.asm.
The size helper is 48 bytes and speed helper 89 bytes; the cached compiler-
builtins baseline is 327 bytes. Both preserve the existing pointer/length ABI,
compare unsigned bytes and return signed i32 ordering in A/B/C/D.

Both compiler Memcmp libcalls and Rust named memcmp calls already target
__rust_memcmp. Register the helpers under that existing export; s/z selects
size and 0/1/2/3 selects speed. No backend symbol or Rust fork changes are needed.

Filter the overridden compiler-builtins definition before reachability, so it
cannot hide the runtime entry or retain its private dependencies. Preserve the
original library order and program-provided definitions. A synthetic link test
checks old-body/dependency exclusion, no duplicate definitions and one selected
helper. This policy only filters compiler-builtins sections.

Bounded direct tests cover zero/odd/even lengths through 1024, high-bit unsigned
ordering, first/middle/last differences, aligned/unaligned pointers, return
sign, stack restoration, unchanged arguments and no non-stack writes. A zero-
length probe supplies distinct end-of-address-space byte values.

Tiny no_core Rust probes at 0/z exercise compare_bytes, a named extern memcmp,
five-byte raw_eq and two-byte inline equality. A CLIF Memcmp libcall is compiled
and executed against both runtime variants. RGBDS links only the small probes,
selected helper and return sentinel; no core or application ROM build is used.

Validation: 17 targeted memory/linkage tests pass in 1.26 seconds. The bounded
move/compare audit reports 586 cases, zero incorrect, using promoted runtime
files and the cached builtins baseline. The audit now bootstraps that baseline
only when absent. Reproduce with cargo run --example audit-move-compare.
Quality: cargo clippy --allow-dirty --fix, cargo fmt, LSP diagnostics and
git diff --check pass. Full core/ROM rebuilds were deliberately avoided;
Rust fork/backend sources and ABI are unchanged.
