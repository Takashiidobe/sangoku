# Select audited memcmp runtime implementations (sangoku-mt4.11)

_2026-11-08 15:25_

## Context

The bounded audit in `wiki/log/2026-11-08-12-05.md` (sangoku-mt4.6) found
independently written SM83 `memcmp` size/opt candidates, but the linker still
pulled in the 327-byte `compiler-builtins` `memcmp`. `sangoku-mt4.11` promotes
the candidates to independent runtime objects selected for `s`/`z` versus
`0`-`3`, ensures both the compiler libcall and Rust named `memcmp` paths select
them rather than `__rust_memcmp` from `compiler-builtins`, avoids duplicate
definitions and preserves the inline equality policy initially.

## Case

Compiler `Memcmp` libcalls and Rust named `memcmp` calls (`compare_bytes`,
extern `memcmp`, `raw_eq`), all targeting `__rust_memcmp`.

## Before

Linked the cached `compiler-builtins` baseline: 327 bytes. The link listing is
not recorded.

## After

`runtime/memory/memcmp/{size,speed}/pointer.asm`: size helper 48 bytes, speed
helper 89 bytes. Both keep the existing pointer/length ABI, compare unsigned
bytes and return signed `i32` ordering in `A`/`B`/`C`/`D`.

## How

Promoted the candidates and registered them under the existing `__rust_memcmp`
export (`s`/`z` size, `0`/`1`/`2`/`3` speed); no backend symbol or Rust fork
changes. The overridden `compiler-builtins` definition is filtered before
reachability, so it cannot hide the runtime entry or retain its private
dependencies; library order and program-provided definitions are preserved, and
only `compiler-builtins` sections are filtered. A synthetic link test checks
old-body/dependency exclusion, no duplicate definitions and one selected helper.

Tests: bounded direct tests cover zero/odd/even lengths through 1024, high-bit
unsigned ordering, first/middle/last differences, aligned/unaligned pointers,
return sign, stack restoration, unchanged arguments and no non-stack writes; a
zero-length probe supplies distinct end-of-address-space byte values. Tiny
`no_core` Rust probes at `0`/`z` exercise `compare_bytes`, a named extern
`memcmp`, five-byte `raw_eq` and two-byte inline equality; a CLIF `Memcmp`
libcall is compiled and executed against both variants. RGBDS links only the
small probes, selected helper and return sentinel. 17 targeted memory/linkage
tests pass in 1.26 seconds. The audit reports 586 cases, zero incorrect, using
the promoted runtime files; it now bootstraps the cached baseline only when
absent (`cargo run --example audit-move-compare`).
`cargo clippy --allow-dirty --fix`, `cargo fmt`, LSP diagnostics and
`git diff --check` pass.

## Alternatives

Full core/ROM rebuilds were deliberately avoided; Rust fork/backend sources and
ABI are unchanged. Equality specialization stays on the existing inline policy.
