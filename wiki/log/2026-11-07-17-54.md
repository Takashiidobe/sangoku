# Document panic and formatting ROM overhead (sangoku-rl0)

_2026-11-07 17:54:42_

Bookkeeping (`sangoku-rl0`, docs, P2). Added a short README note to avoid
methods that can call panic or formatting code indirectly: retained failure
paths can consume ROM even when never executed, which matters on a 32 KiB
cartridge. It recommends fallible accessors, direct serial output and checking
build warnings. Documentation-only change; clippy, fmt and diff checks pass.
