# f32 int conversions and f16 (sangoku-7qz.8.4, sangoku-7qz.8.5)

_2026-11-07 05:10_

## Context

Last of the float tickets. 8.4 (P0) asked for `fcvt_from_sint`/`uint`,
`fcvt_to_sint`/`uint` and `_sat` for `i8`/`i16`/`i32`, with traps via `rst $10`.
8.5 asked for `fpromote`/`fdemote` plus `f16` ops as promote, op, demote
(correctly rounded for add/sub/mul/div/sqrt), tested against a reference `f16`.

## Case

`x as f32`, `f as i32` (trapping and saturating forms), and any `f16`
arithmetic.

## Before

Conversions and all `f16` ops unsupported.

## After

All lower; tests use `tests/fixtures/emulate/float-convert.clif`.

## How

- New libcalls `GbcFcvtFromInt32` (`i32` + signed flag), `GbcFcvtToInt32` (`f32`
  - mode byte: bit0 unsigned, bit1 saturating, bits2-3 width code),
    `GbcF16ToF32`, `GbcF32ToF16`. Narrow ints are sign/zero-widened to `i32` in
    lowering and the result's low bytes are taken.
- to-int: builds a per-mode limit L (signed max, +1 when negative; unsigned max,
  0 when negative), compares the truncated magnitude against it, then negates
  for negative inputs. NaN or out-of-range hits `rst $10` unless saturating (NaN
  -> 0).
- from-int: negate, normalize to bit 31, jam-shift to bit 30, reuse
  `sf_roundpack`.
- `f16`: promote is exact (subnormals normalized); demote rounds nearest-even by
  assembling the 11-bit significand + guard/sticky and letting the carry bump
  the exponent, clamping to inf. All `f16` arith/cmp/round/sqrt/min/max/int-conv
  lower as promote, `f32` op, demote. Double rounding is harmless for + - \* /
  sqrt because `f32` has >= 2p+2 bits.
- Tests: `int_to_f32`, `f32_to_int` (sat + in-range trapping),
  `f32_to_int_traps_out_of_range`, `f16` promote/demote vs a brute-force
  reference, `f16` ops over all sample pairs. `fdiv` and a trap case were
  sabotaged to confirm they fail.
