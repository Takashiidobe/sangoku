# Cranelift 8c3e0b80 — Lower unconditional jumps

_2026-11-05 10:36:54_

## Context

Until now only straight-line, single-block functions compiled. Commit `8c3e0b80`
(Cranelift fork, `third_party/wasmtime`) supports functions with multiple basic
blocks. No bead id is recorded.

## Case

Test `compiles_unconditional_jump_to_lr35902_machine_code`: an entry block that
`jump`s to a block that returns.

## Before

Branch lowering was absent; any `jump` was unsupported.

## After

```rust
Inst::JumpKnown { dst } => {
    sink.put1(0xC3);
    sink.use_label_at_offset(sink.cur_offset(), *dst, super::LabelUse::JumpAbs16);
    sink.put2(0);
}
```

The test expects exactly `[0xC3, 0x03, 0x00, 0xC9]` (`jp $0003; ret`).

## How

`isa/lr35902/lower.rs` adds branch lowering; `inst/mod.rs` and `inst/emit.rs`
add the jump instruction and target patching. The code buffer resolves the label
address after block layout.

## Alternatives

Conditional branches are handled in a later lowering change. Only the absolute
`jp` form is emitted here.
