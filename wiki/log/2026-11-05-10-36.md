# Cranelift 8c3e0b80 — Lower unconditional jumps

_2026-11-05 10:36:54_

## Files and implementation

`cranelift/codegen/src/isa/lr35902/lower.rs` adds branch lowering, and
`inst/mod.rs` / `inst/emit.rs` add the jump instruction and target patching. The
emitted form is an absolute LR35902 jump:

```diff
+Inst::JumpKnown { dst } => {
+    sink.put1(0xC3);
+    sink.use_label_at_offset(sink.cur_offset(), *dst, super::LabelUse::JumpAbs16);
+    sink.put2(0);
+}
```

The code buffer resolves the label address after block layout. Unconditional
jumps are the first control-flow case; conditional branches are handled later.
This grows the minimal straight-line compiler toward control flow used by
compiler-generated functions.
