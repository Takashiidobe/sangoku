# Fix primes stack corruption

_2026-11-07 17:21:48_

The primes example placed a 141-byte main frame plus iterator calls on the stack starting at $FFFE. The stack entered $FF00 I/O and writes to $FF01/$FF02 produced garbage serial output. Move startup and ROM emulator harness stacks to $E000 so they grow into work RAM. Correct the example to count noncomposites from index 2 and return that count. Add work-RAM stack checks to the example regressions. No compiler or array implementation change was needed.

Validation: primes prints 15 primes and returns 15; hello ROM builds. Clippy, fmt, and LSP diagnostics pass. Nextest: 130/131 pass; sort still exceeds ROM capacity (sangoku-30k.9.1.15).
