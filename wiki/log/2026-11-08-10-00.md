# Add a visible Game Boy screen demo (sangoku-bha)

_2026-11-08 10:00:37_

## Context

Only the serial example existed, so nothing showed on an emulator screen.
sangoku-bha (P1) asked for a small standalone Rust example that initializes the
display safely, loads a small font/tile set and draws visible text, without
changing the serial example or compiler architecture.

## Case

`examples/screen.rs`: drawing text through LCD, VRAM and palette registers, with
LCD/VRAM access rules respected.

## Before

No screen demo; built-in runner has a graphics limitation.

## After

`examples/screen.rs` has a small uppercase tile font, a greeting and
`ufmt`-formatted arithmetic. Built at levels 0 and `z`; the user verified the
demo in SameBoy.

## How

Waits for a fresh VBlank, loads VRAM with the LCD off, then enables the
background display. Bounded checks cover LCD access, tile data, text and
palette; all six example tests pass. Documented external-emulator build/open
commands. Cargo fmt, rustfmt and clippy pass. Closed sangoku-bha.

## Alternatives

None recorded.
