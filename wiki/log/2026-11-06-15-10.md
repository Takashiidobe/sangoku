# Select native SM83 popcount by optimization intent

Completed sangoku-pg3. The compiler bridge retains unoptimized versus optimized
shared flags and passes Rust s/z intent through the new LR35902
optimize_for_size ISA flag. Other targets retain their settings. Levels 1/2/3
use parallel counting; 0 and s/z use the compact shift loop. The two
unoptimized/size cases share an algorithm while remaining distinguishable for
future lowering decisions.

Popcnt16 consumes fixed B/C inputs, produces A/B outputs and declares scratch
C/D clobbers, plus E for parallel counting. The allocator preserves live source
values normally. Both kernels leave HL untouched and use no tables or private
stack. The 12/50-byte instruction bodies replace sixteen generic expansions; RET
gives the audited 13/51-byte helpers. The instruction-size bound is increased to
accommodate the larger kernel. Native bytes match the audited RGBDS images.

The build/example commands accept --opt-level 0|1|2|3|s|z (default 0), including
--opt-level=z. cargo run -- build game.rs game.gb --opt-level 2 selects speed.
Two CLI tests cover level/position/default handling and invalid options.

Reproduce: python -B tests/check_popcount.py --exhaustive16

All 35 LR35902 codegen tests and 1918408 executions pass. Every one of the four
Rust probes runs all 65536 inputs at each of six levels, plus independent
seed-11 pairs, poisoned registers and alternate stacks. The pressure input pair
uses other=(40503\*input+12345)&65535 for its full-domain sweep, not all u16
pairs. Probes cover u16 counts, zero-extended u32 counts, input reuse, and two
counts with both inputs live. Compiler IR verification and allocation checking
are on. The run also includes 12096 general stack accesses and 1024 independent
pressure/ incoming-argument checks from sangoku-7em.

Actual narrow Rust bodies: 0 uses 27 bytes/728 T-cycles, 1/2/3 use 57/248, and
s/z use 19/696, including RET and compiler CFG overhead. Their peak stack is two
return-address bytes. The spill-heavy two-input probe takes 166/2488, 245/1708
and 153/2436 respectively, with peak stack 14 bytes. Full narrow/wide/
live/pressure tables and limitations are in wiki/audits/popcount16.md.

Commands, fixture assembly, objects, ROMs, maps, symbols, hashes and
results.json are retained in build/popcount-replacement. After formatting, all
six rebuilt Rust ROM images match the exhaustively tested images byte for byte.
All 50 Python unit tests, two CLI tests, Ruff checks/format, cargo clippy
--allow-dirty --fix, cargo fmt and git diff --check pass. Blank ROM smoke builds
pass at default 0, 2 and z. Existing compiler warnings remain. Unrelated
preexisting submodule and Beads JSONL edits remain outside these commits.
