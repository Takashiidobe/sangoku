# 7qz.8.1: f32/f16 as byte-register types

- `rc_for_type`: F32 shares the I32 byte parts, F16 the I16 parts, so moves, spills, the ABI (including stack returns), call and return need no float class.
- Lowering: load/store/select accept F16/F32; f16const/f32const load the bit pattern; same-size bitcast is per-byte moves; fneg/fabs/fcopysign touch only the top byte (xor 0x80, and 0x7f, merge sign).
- Test: fixtures/emulate/float-bits.clif + lowered.rs f32_sign_ops_select_and_const_match_host (NaN, inf, +-0, subnormal, MAX against host bits). f16 shares the code paths but has no dedicated runtime test.
- Coverage matrix: f32 call, f.const, fabs, fcopysign, fneg, load, select, store now ok. Arithmetic, fcmp, conversions remain for 8.2-8.5.
