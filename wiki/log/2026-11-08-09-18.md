# Integrate ufmt serial output

_2026-11-08 09:18:25_

## Context

Examples formatted output by hand. No bead id was recorded in the original log.
This adds `ufmt` so standalone Rust inputs get formatted serial output without
retaining `core::fmt`.

## Case

`hello`, `primes` and `sort` examples writing numbers and text to the serial
port by hand.

## Before

Manual output code in each example; `ufmt` not available to standalone inputs.

## After

Precompiled `ufmt` dependencies and an infallible serial console are available;
`hello`, `primes` and `sort` use them. Verified exact serial output, numeric and
Unicode edge cases, no retained `core::fmt`, 160 default tests, six optimization
profiles, clippy, and a relocated bundle with only RGBDS on `PATH`.

## How

Bundles include target metadata, assembly and host procedural macros.

## Alternatives

Not done: general Cargo project dependency resolution is separate work (see
sangoku-61a).
