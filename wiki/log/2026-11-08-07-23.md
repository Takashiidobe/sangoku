# Elide dead HL saves from SM83 stack accesses (sangoku-30k.9.1.9.1)

_2026-11-08 07:23:47_

## Context

Stack-slot accesses were wrapped in saves because the emitter could not know
whether `HL`/`AF` were live; `alloc.s` at opt 0 had about 11.6k such accesses
(7+ bytes each). sangoku-30k.9.1.9.1 (P0) first dropped the `AF` save (wasmtime
`c4b3e3ca`); this step (`c5535f19`) drops `push hl`/`pop hl` when `HL` is dead.

## Case

Any spill/reload or stack-slot byte access.

## Currently emits

```asm
push hl
ld hl, sp+N+2
ld r, [hl]
pop hl
```

## Should emit

The same without `push hl`/`pop hl` when `HL` is dead after regalloc; `A` is
preserved for `H`/`L` stores when live. Exact final listing not recorded. ROM
used bytes from RGBDS `probe.map`, same sources and levels:

```text
program  opt  before  after
hello    0      3616   3324
hello    z      2265   2089
heap     0     55382  48102
heap     z     32031  26191
```

## How

Physical-register liveness covers original operands, clobbers, allocator edits
and CFG successors. `LoadStack8`/`StoreStack8` omit `HL` saves when dead;
assembly printing follows native emission, including stack-return loads.
Prologue/epilogue code keeps conservative preservation.

Tests: CFG-loop liveness unit test, live `H`/`L`/`A` cases, a pressure FileCheck
fixture; two lower fixtures and the incoming-argument byte expectation updated.
`check-spills` uses nextest and checks native/RGBDS agreement. Rebuilt pinned
`cg_clif`; 36 SM83 backend tests, the dataflow test and all 171 nextest tests
pass. Spill audit: 12096 original access, 1344 liveness, 1024 pressure
executions plus Rust probes. Clippy, fmt, LSP and diff checks pass.

## Alternatives

Not done: heap opt 0 still exceeds the 32 KiB cartridge limit (heap builds use
`--alloc`; the optimized ROM executes and returns 52). No push.
