# Legalize i128 into four i32 limbs

_2026-11-06 22:17:25_

Extended LR35902 wide-value legalization to i128/u128 as four low-to-high i32
limbs across signatures, control flow, calls, returns, memory and conversions.
Added carry/borrow arithmetic, checked add/sub, comparisons, counts and
reordering. Wrapping multiplication uses a bounded 128-step loop; shifts/rotates
use at most 127 steps to bound ROM size. Integer-only ROM builds now omit unused
soft-float helpers. All 97 nextest tests pass, including none/speed
host-reference emulator checks and Rust u128 memory operations through CLIF and
RGBDS. u128 addition and multiplication ROMs build at opt levels 0/2; blank and
u64 smoke builds pass. Remaining native i128 arithmetic is tracked by
sangoku-7qz.9.3; ordinary Rust floating MIR remains blocked by the existing
frontend gate.
