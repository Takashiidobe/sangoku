# 7qz.8.6: fused multiply-add for f32/f16

- `__gbc_ffma32(a, b, c, odd)`: exact 48-bit product (mul loop extracted into `sf_mul48`, shared with fmul) placed in a 64-bit field with the 24-bit addend aligned to it; the smaller operand is shifted right with jamming, then add or subtract, normalize to bit 63, jam into wM and use `sf_roundpack`. Special cases: NaN, inf*0, inf-inf, zero product (signed zero rules), exact cancellation gives +0.
- f16 fma passes odd=1: the f32 result is rounded to odd (low 7 guard bits collapsed into bit 7) so the following demote to f16 does not double round. Disabling it makes the f16 test fail.
- Tests: f32_fma_matches_host (edge triples + 500 random with exponents near cancellation) vs `f32::mul_add`; f16_fma_matches_reference (all sample triples) vs f64 mul_add + brute-force f16 rounding. Sabotaged both.
- f16/f32 coverage matrix now has no unsupported ops except i64/f64/f128 cases.
