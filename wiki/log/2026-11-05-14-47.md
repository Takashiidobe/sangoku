# Cranelift e9a49131 — Support multi-register return pointers

_2026-11-05 14:47:28_

## Files and implementation

`cranelift/codegen/src/machinst/lower.rs` removes the assumption that a
structure-return pointer occupies exactly one register:

```diff
-assert!(regs.len() == 1);
 let sret_reg = sret_param.map(|param| value_regs[param]);
```

The pointer is kept as `ValueRegs`, so split-pointer values can flow through
generic lowering. The implementation updates the shared machine backend
abstraction rather than special-casing LR35902; actual stack-return-value
support is still incomplete in the target ABI.

Commit: `e9a49131` — Cranelift (`third_party/wasmtime`). Purpose: Remove a
Cranelift lowering assumption that blocked multi-register target values. Change:
Adjusted generic machine lowering to carry return pointers represented by
multiple registers. Implementation: Changed the return-pointer handling in
`machinst::lower`/VCode rather than adding an LR35902-only special case. Design
choice: Fixing the shared abstraction lets other split-register targets use the
same path.
