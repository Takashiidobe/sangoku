# rust 1d27b394 — Add LR35902 C ABI classification

_2026-11-05 13:40:26_

## Files and implementation

The Rust fork adds `compiler/rustc_target/src/callconv/z80.rs` and dispatches
`Arch::Other("z80")` to it from `callconv/mod.rs`:

```diff
+if arg.layout.pass_indirectly_in_non_rustic_abis(cx)
+    || arg.layout.is_aggregate()
+{
+    arg.make_indirect();
+}
```

Aggregate returns are also classified indirect. This is rustc's foreign/C ABI
classification layer; it complements but does not replace the Cranelift
backend's function calling convention. Without this dispatch, foreign-ABI
signature lowering panics for the custom architecture.

Commit: `1d27b394` — Rust (`third_party/rust`). Purpose: Let rustc classify
foreign-ABI arguments and returns for the target instead of panicking for an
unknown architecture. Change: Register `z80` ABI classification and mark
aggregate returns/arguments indirect; also route the target architecture to the
classifier. Implementation: Added `callconv/z80.rs` and dispatch from
`rustc_target::callconv` for `Arch::Other("z80")`. Design note: This is the
target's C ABI classification; it does not by itself implement the full Rust ABI
in Cranelift.
