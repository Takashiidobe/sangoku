## Files and implementation

`isa/lr35902/lower.rs` adds `icmp`, `brif`, `load`, and `store` cases;
`inst/emit.rs` implements their machine sequences. A memory access copies the
16-bit address into HL, applies its offset, then accesses one or two bytes:

```diff
+emit_ld_r_r(sink, regs::Gpr8::H as u8, regs::Gpr8::B as u8);
+emit_ld_r_r(sink, regs::Gpr8::L as u8, regs::Gpr8::C as u8);
+emit_mem_address(sink, offset);
+sink.put1(0x7E); // ld a, [hl]
```

The implementation models H/L/A as fixed clobbers so allocation respects the
address and accumulator scratch registers. Compare helpers produce a boolean
from LR35902 flag behavior; conditional branches encode both successors. These
operations cover common memory/control-flow patterns emitted by `core`.
