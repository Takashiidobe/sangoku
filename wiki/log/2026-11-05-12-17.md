# Cranelift 7c8ed600 — Add comparisons, branches, loads, and stores

_2026-11-05 12:17:23_

## Context

Control flow and memory access are what compiler-generated code consists of, and
none of `icmp`, `brif`, `load` or `store` lowered yet. Commit `7c8ed600` in
Cranelift (`third_party/wasmtime`); no bead.

## Case

CLIF `icmp`, `brif`, byte/word `load` and `store`.

## Before

Not lowered.

## After

A load or store copies the 16-bit address into `HL`, applies the offset, then
accesses one or two bytes:

```asm
ld h, b
ld l, c
inc hl        ; repeated per offset byte (dec hl when negative)
ld a, [hl]
ld <dst>, a
```

Word accesses insert `inc hl` between the low and high byte. `BranchIf` loads
the condition into `A`, `or a` (`0xB7`), then `jp nz, taken` followed by
`jp not_taken`, both with absolute 16-bit label relocations.

## How

`lower.rs` selects `Compare8`, `Compare16`, `LoadMem8/16`, `StoreMem8/16` and
`BranchIf`; `inst/emit.rs` implements them. `H`, `L` and `A` are fixed clobbers
so allocation respects the address and accumulator scratch. Compare helpers
produce a boolean from flag behavior. Tests exercise comparisons, branches and
memory operations.

## Alternatives

Scope is the subset for simple functions, not full Rust memory or ABI semantics.
The `HL` copy per access is the cost later addressed by `[de]` loads
(sangoku-dq5, 2026-11-09-14-17).
