# rustc_codegen_cranelift 9bca4bc — Reject C variadic calls

_2026-11-05 13:23:11_

## Context

The generic `adjust_call_for_c_variadic` path assumes a mature C ABI, but the
LR35902 argument ABI (seven byte registers plus the new stack arguments) cannot
express C varargs. Generating code anyway would silently misrepresent argument
passing. Commit `9bca4bc` in `rustc_codegen_cranelift`; no bead.

## Case

A call to a function with `fn_abi.c_variadic` set, such as a C `printf`-style
extern.

## Before

Generic varargs lowering ran and produced invalid ABI code.

## After

```text
C variadic calls are not supported on the LR35902 target
```

reported at the call's source span.

## How

`src/abi/mod.rs`, in `codegen_terminator_call`, checks
`Arch::Other("z80".into())` before `adjust_call_for_c_variadic`, and calls
`span_fatal`.

## Alternatives

Supporting varargs is deferred until the target's stack/register argument ABI is
complete.
