# Add division execution and runtime audit reporting

Completed sangoku-mt4.1 from base 7a0f9ca. Extended tests/emu.py with PUSH/POP,
calls/returns/jumps, RST, 8-bit ALU/compare/borrow instructions, INC and pair
arithmetic, carry/bit operations and stack-pointer adjustments. Added peak stack
and written-address counters with explicit metric reset. Instruction costs/flags
reference the RGBDS gbz80 CPU manual.

Added runtime_harness.py for RGBDS assembly, symbols, section sizes and source
hashes. audit_runtime.py emits helper/caller T-cycles, code/table/caller ROM,
declared/touched scratch RAM, peak stack, results, observed register changes,
tool versions and commands. Optional artifact directories retain assembly,
objects, ROMs, maps and symbols. See wiki/runtime-audits.md for scope and usage.

Validation commands: python -B -m unittest discover -s tests -v python -B
tests/audit_runtime.py --output build/runtime-audit.json --artifacts
build/runtime-audit python -B tests/audit_runtime.py --helper udiv16 --helper
urem16 --lhs 1 --rhs 1 --output build/division-audit.json --artifacts
build/division-audit

All 33 tests passed: exhaustive SUB/SBC/CP results/flags (262,144 cases), 622
division-core cases with explicit BC dividend and D/E divisor low/high (seed 0),
divide-zero vector handling, 10,256 multiplication pairs, control flow/stack
tests, and independent report size/stack/scratch/cycle checks. Default report:
ten cases with correct body and caller results.

For operands 1,1: mul16 body/caller = 484/592 clocks, 30 helper code bytes, 18
caller bytes, 4 peak stack bytes, no table or scratch allocation. The nested
stack fixture = 180/288 clocks, 24 helper code + 2 table + 18 caller bytes, 10
peak stack bytes, 4 allocated scratch bytes and 1 written byte.

Division reports intentionally exit 1: current udiv16(1,1) returns 256; urem16
returns 32201 in isolation and 27683 through the caller because of uninitialized
input state. Both are incorrect. The linked division object is 97 bytes
including both helpers. These are defect reproductions, not accepted performance
candidates; runtime fixes remain under sangoku-mt4.2.1.

Coverage: flat ROM0/WRAM0, instruction subset, synthetic ABI callers. Body stack
accounting includes a preexisting 2-byte return and 2-byte argument slot. No
peripherals, interrupts, banking or bus timing; trap handler not executed. Ruff
checks/format, cargo test --bins, cargo clippy --allow-dirty --fix, cargo fmt
and git diff --check passed. No compiler or runtime source changes.
