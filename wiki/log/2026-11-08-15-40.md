# Bounded native-width multiplication implementation

sangoku-mt4.10 and children .1/.2: User explicitly requested a few correctness
cases and size/performance implementations for i8/i16/i32, replacing the
original extensive SDCC comparison scope. No exhaustive or random audit ran.

Add GbcMul8, its native (i8,i8)->i8 signature and both runtime symbol mappings.
i8 wrapping multiplication now calls __gbc_mul8 without widening. Existing
GbcMul16/GbcMul32 paths select their width's runtime variant. No Rust fork or
compiler-builtins changes are necessary. Signed/unsigned wrapping share code.

| Width | Size bytes | Speed bytes | Size / speed cycles, max × max |
| --- | --- | --- | --- |
| 8 | 13 | 50 | 344 / 212 |
| 16 | 30 | 171 | 912 / 672 |
| 32 | 108 | 236 | 12060 / 10208 |

Retain the existing compact i16/i32 algorithms; add a compact native i8 loop.
Speed i8/i16 unroll all steps; speed i16 keeps the eight-bit right-operand
shortcut. Speed i32 unrolls four steps between termination tests. Common .inc
files share step definitions, without extra runtime helper dependencies.
Levels s/z select size; 0/1/2/3 select speed. One object per referenced width.

Cycles cover helper entry through RET, excluding caller packing/spills/CALL.
The speed label describes a tradeoff, not a win on every input: i32 1×1 costs
776 compact cycles versus 1424 unrolled cycles; zero costs 412 versus 416.
i8/i16 allocate no stack, i32 allocates eight bytes, and all use zero tables
or scratch RAM. Public helpers may clobber all general registers and flags.

Eight explicit operand pairs per width cover zero in either position, 1×1,
max×max, high-bit overflow, mixed patterns and narrow operands in either
position. Both variants match host wrapping results and preserve stack/args.
Tiny no_core Rust fixtures at 0/z check signed/unsigned native calls and live
inputs on six of these pairs. No core or complete application ROM was built.

Validation: 14 focused linkage/multiplication tests pass in 1.28 seconds; the
final two multiplication tests pass in 0.17 seconds. All 36 LR35902 backend
unit tests pass. Historical compact mul16 caller/size/cycle regression passes.
Pinned release backend rebuilt; clippy --allow-dirty --fix, fmt, LSP diagnostics
and diff checks pass. Compatibility harnesses retain compact mul16 for old
measurements; production selects variants from the family registry.
Reproduce: cargo nextest run --no-fail-fast -E 'binary(multiply)'.
