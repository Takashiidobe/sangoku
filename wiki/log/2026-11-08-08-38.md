# Remove panic-only formatting at every optimization level (sangoku-7w9)

_2026-11-08 08:38:31_

## Context

`examples/sort.rs` with `sort_unstable` exceeded ROM capacity because
immediate-abort builds still retained panic formatting. sangoku-7w9 (P1 bug)
removes panic-only formatting through compiler configuration only, with no
Rust/core/backend source edits. Result: sort retained bytes 53507 -> 11678 at
opt 0 and 9202 at levels 1-z, with no `core::fmt` sections.

## Case

`sort_unstable` on a slice: bounds and assert panics carry formatting arguments
that are only used on the panic path.

## Currently emits

Dead formatting argument arrays and formatter pointers stayed live through MIR
debug-local records: sort 53507 retained bytes (previous level 0), `core::fmt`
sections present.

## Should emit

Retained section bytes (RGBDS map totals):

```text
codegen level  sort bytes  core::fmt sections
0                  11678   0
1                   9202   0
2                   9202   0
3                   9202   0
s                   9202   0
z                   9202   0
```

## How

- Shared defaults at all six codegen levels add MIR level 2 and
  `-Zmir-strip-debuginfo=all-locals` alongside immediate-abort and MIR inlining;
  stripping the debug-local records lets upstream dead-store elimination remove
  the references. Checks still trap; panic arguments retain effects.
- Target library caches fingerprint rustc options and invalidate the marker
  before rebuilding, so changed defaults cannot reuse old metadata or assembly.
  All affected library sets were rebuilt.
- Tests: the all-level matrix (extensive only) runs exact sort output, formatted
  panic/`assert_eq`/`Result` unwrap/`Option` unwrap with volatile argument
  effects, and valid/invalid slice ranges. Default checks verify explicit `u8`
  formatting on 0/123/255 and constant panic `E0080` errors. The oversized
  formatting fixture now formats a value explicitly (diagnostic regression still
  covered). Regenerated 27 MIR/CLIF checks with `tools/update_filecheck.py`; no
  fixture sources changed.
- Validation: 159 default tests passed in 8.758s, none above 10s; six-level
  matrix passed in 151.677s with cold rebuilds; extensive numeric conversions in
  4.663s. Clippy, fmt, LSP, diff checks pass. Hello links (1022 retained bytes);
  default-level heap fits (30195 bytes) and returns 52.

## Alternatives

None recorded. ROMs stay padded to 32768 bytes. No push.
