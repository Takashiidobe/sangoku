# Prototype an archived single-file compiler distribution

_2026-11-07 18:18:58_

Added a static musl launcher that detects an appended gzip/tar toolchain archive, verifies its SHA-256 checksum and atomically extracts it into a digest-keyed cache. Concurrent extraction and cache reuse are covered. Packaged the pinned rustc driver, backend, host loader/shared libraries, standalone CLIF lowerer, target core/builtins for all six optimization levels, runtime assembly, target/header assets and examples. RGBDS stays external. Bundled builds invoke extracted tools directly without Cargo/rustup or source checkout; build artifacts belong to the caller directory. Frontend and CLIF commands now supply explicit target library metadata. Added packaging and bubblewrap smoke-test scripts plus short distribution documentation. Built build/dist/sangoku: 215137171 bytes (~205 MiB), Linux x86-64 static launcher with dynamically linked compiler components extracted on first use. Isolated test hides checkout, exposes only RGBDS on PATH, uses a relative cache path with spaces, and passes 13 invocations including three executed examples, six optimization levels, example/MIR/CLIF/lower commands and cache reuse. Full nextest 139/139 pass; clippy/fmt/LSP/diff checks and Python syntax checks pass. No vendored source changes.
