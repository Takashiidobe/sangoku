# Preserve registers and flags across SM83 spills and reloads

Completed sangoku-7em. LoadStack8 and StoreStack8 now preserve AF and HL around
stack addressing, adjusting the requested offset by their four temporary stack
bytes. Loads into A/H/L replace the corresponding saved byte before restoring
the pairs. Other byte loads go directly from [HL] into their destination. Stores
capture the original source before computing the address. No general register is
reserved, and the obsolete allocator clobbers are removed.

Large stack offsets use ld hl,imm16 followed by add hl,sp. This bounds the new
stack sequences within the declared instruction-size limit when the temporary
saves push an offset beyond the signed-byte range. RGBDS pretty printing and
native byte emission produce identical bytes for all 126 access fixtures.

Run: python -B tests/check_spills.py --exhaustive16

The check runs the pinned LR35902 codegen tests, rebuilds the pinned backend,
compiles both Rust probes, assembles their actual output and executes it using
tests/emu.py. Logs, generated assembly/native bytes, objects, ROMs, maps,
symbols, source hashes, build commands and results.json remain in
build/spill-repair. It enables std,lr35902,x86 for the codegen tests because an
existing shared ISLE helper is feature-gated to native targets; the production
build path is unchanged.

All 34 targeted codegen tests and 171498 executions pass. The access matrix has
12096 executions across seven registers, load/store, nine offsets from 0 to 511,
all 16 flag combinations, three register patterns and two stacks. Checks cover
every unrelated register, flags, SP restoration, four-byte peak scratch stack
and memory-write bounds. An independent twelve-value CLIF sum and incoming
stack-argument function pass 1024 executions. The latter uses the current B/C/A
argument ABI and reads argument eight from stack offset four after the return.

Both the original Rust popcount probe and input-plus-popcount probe pass all
65536 word values, plus 13653 boundary/random/poison/alternate-stack executions
each (seed 7). The probes occupy 214/235 bytes, take 988/1168 T-cycles including
RET, and peak at 8/10 stack bytes including the return address. These are
correctness controls; the separate optimization remains sangoku-pg3.

python -B -m unittest discover -s tests passes all 50 existing unit tests. cargo
run -- build examples/blank.rs build/blank.gb produces the ROM. Ruff
check/format, cargo test --bins, cargo clippy --allow-dirty --fix, cargo fmt and
git diff --check pass. Existing compiler warnings remain. Prior unrelated
submodule edits and Beads JSONL edits are retained outside these commits.
