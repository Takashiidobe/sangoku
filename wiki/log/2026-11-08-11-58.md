Helper callers cost 30 bytes for copy, 55 for fill, independent of these lengths.
Add helper ROM once per linked program: copy 32/57 bytes, fill 24/43 (size/opt).
Peak stack includes the outer return address: inline copy 4/6/10/10/10 bytes,
inline fill 2/4/4/4/6; helper copy 13; helper fill 13/15 (size/opt).
All cases use zero table/scratch RAM. ROM cost depends on helper reuse.

For this caller shape, inline copy wins cycles at 1–4 bytes; helpers win at
8/16. Inline fill wins through 8; opt helper wins at 16, whereas size helper
trades slower execution for smaller ROM at 16. Existing backend spill/frame
cost makes 16-byte inline copy 335 bytes. These are sampled crossovers, not
universal thresholds. Retain both strategies; defer threshold changes until
checking the existing lowering policy. Broader audit tasks remain open.
