_2026-11-05 14:53:04_

## Files and implementation

`third_party/rustc_codegen_cranelift/src/base.rs` translates the backend's
`CodegenError::Unsupported(reason)` into a rustc diagnostic:

```diff
+Err(ModuleError::Compilation(CodegenError::Unsupported(reason))) => {
+    dcx.fatal(format!(
+        "LR35902 backend cannot compile `{name}`: {reason}",
+        name = codegened_func.symbol_name
+    ));
+}
```

The diagnostic names the generated function and unsupported operation. This
makes each core compile attempt useful for choosing the next lowering change
instead of ending in a backend panic or generic module error.
