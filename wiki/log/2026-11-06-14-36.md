# Audit SM83 population count (sangoku-mt4.3)

_2026-11-06 14:36_

## Context

`sangoku-mt4.3` and its children. `popcnt.i16` was expanded into sixteen generic
bit-processing steps, which is both big and slow for a CPU with no popcount
instruction. The audit compares eleven implementations. Verdict (Replace: YES):
native table-free parallel counting, a runnable prototype of 51 code bytes and
216 T-cycles including `RET`, preserving `HL`, with no table or owned scratch
RAM. Production replacement is separate task `sangoku-pg3`.

## Case

`ctpop` on a `u16`.

## Before

The pinned compiler probe emits 207 bytes and miscompiles: input zero returns 11
or 12 depending on the stack address. Allocation-generated spill and reload
edits overwrite live `HL` while computing stack addresses. General repair is
tracked in `sangoku-7em`; production compiler sources are unchanged here. An
audit-only push/pop repair is correct at 211 bytes and 936 cycles.

## After

Compared eleven correct implementations with body, complete caller, live-input
caller and eligible inline modes:

- smallest loop: 13 bytes/664 cycles
- page-aligned nibble lookup: 34 code + 16 table bytes/164 cycles
- byte lookup: 10 code + 256 table bytes/60 cycles
- parallel counting: 51 bytes/216 cycles (default recommendation)

Alignment gaps and caller saves are separate costs. Mandatory tables and
unconditional outlining: NO. SDCC (built `~/sdcc` out of tree with only SM83
enabled): its width-specialized generic count-ones C loop compiles to 42 adapted
bytes/5232 cycles; no dedicated Z80/SM83 popcount routine was found.

## How

Frozen Rust/SDCC output, source hashes, versions and build commands are in
`tests/fixtures/popcount/provenance.json`. Reproduction and tradeoffs:
`wiki/audits/popcount16.md` with assembly fixtures, baseline generator and CSV;
objects, ROMs, maps, symbols, hashes and JSON in `build/popcount-audit`.

```text
python -B tests/audit_popcount.py --samples 1024 --seed 0 --exhaustive16 \
  --output build/popcount-audit/results.json \
  --artifacts build/popcount-audit/artifacts --csv wiki/audits/popcount16.csv
```

All 342928 accepted executions pass, including the complete u16 domain for
parallel counting and all three lookup variants. The frozen broken output is
isolated from accepted timings; regenerated compiler output matches its frozen
image; fixture formatting changes were checked for ROM byte equivalence. All 50
unit tests pass (poisoned scratch state, alternate stacks, live inputs,
exhaustive SWAP flags/timing). Ruff, `cargo test --bins`, clippy, fmt and
`git diff --check` pass. No vendored sources changed; `svn status` on the SDCC
checkout is clean.
