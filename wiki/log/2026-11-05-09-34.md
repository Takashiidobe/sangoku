`cranelift/codegen/src/isa/lr35902/lower.rs` adds the first useful CLIF cases:
I8 constants, returns, and addition. The emitter defines the target sequence for
addition, using A when operands are elsewhere:

```diff
+Opcode::Iadd if ctx.output_ty(ir_inst, 0) == types::I8 => {
+    let lhs = ctx.put_input_in_regs(ir_inst, 0).only_reg()?;
+    let rhs = ctx.put_input_in_regs(ir_inst, 1).only_reg()?;
+    let dst = ctx.alloc_tmp(types::I8).only_reg()?;

```

an I8 add/return and a register-pressure case with spills. This minimal opcode
set bootstraps actual functions while leaving all other CLIF operations
unsupported.
