## Files and implementation

`third_party/rustc_codegen_cranelift/src/driver/aot.rs`, `base.rs`, and the new
`src/rgbds.rs` add an AOT-only assembly path. The formatter creates one RGBDS
section per codegen unit and exports Rust functions:

```diff
+pub(crate) fn new_source(module: &str) -> String {
+    format!("SECTION \"{}\", ROM0\n\n", symbol_name(&format!("cgu_{module}")))

+writeln!(source, "EXPORT {symbol}\n{symbol}::").unwrap();
```

The AOT driver passes an optional assembly buffer through codegen and collects
the target's pretty-printed machine instructions. Tests run `rgbasm` and
`rgblink` when installed. Assembly-only output lets `core` be compiled without
requiring a ROM linker/runtime during codegen bring-up.
