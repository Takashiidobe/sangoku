# Select compact or unrolled memcpy by optimization level

_2026-11-08 11:40:00_

sangoku-mt4.5.3: Split memory.asm into independently selected memset,
memmove, memcpy_size and memcpy_opt objects. The linker chooses size for s/z
and opt for 0/1/2/3; exactly one memcpy body is linked, without runtime dispatch.
memmove retains the previous overlap-safe algorithm. Both copy variants retain
the split ABI, destination return and caller-owned stack arguments.

memcpy_size uses a zero-guarded byte loop equivalent to the supplied gbdev
example. memcpy_opt retains the SDCC-derived four-byte forward loop; provenance
and license remain in runtime/NOTICE. No vendored sources changed.

ROM: size 32 bytes; opt 57 bytes. No tables or owned scratch RAM.
Both clobber caller-saved registers; arguments occupy 3 stack bytes, return
address 2, and maximum additional saved/transient stack 6 bytes (11 total).
The bounded emulator comparison uses source $c400 and destination $c600.
T-cycles below include entry setup and RET, exclude caller setup/CALL/cleanup:

Reproduce the table: cargo nextest run --no-fail-fast -E 'binary(memory)' --success-output immediate
Correctness: tests/memory.rs checks both variants against a host model over
zero, small/unroll and 255/256/257/511 lengths, both address orders, guard bytes,
return values, stack and arguments; 40 random cases use seed 0x6d656d.
Validation: cargo nextest run --no-fail-fast (172 passed, 17 profile exclusions).
Formatting: cargo nextest run --profile extensive --no-fail-fast -E 'test(=upstream_u64_decimal_formatting_matches_host)' (passed).
Smoke: cargo run -- build examples/hello.rs build/hello.gb (passed), also --opt-level z.
Quality: cargo clippy --allow-dirty --fix, cargo fmt, LSP source errors (none).
This implements the requested selection policy; the full copy/fill audit,
including caller costs, inline candidates and fill comparisons, remains open.
