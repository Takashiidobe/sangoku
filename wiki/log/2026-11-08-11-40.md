# Select compact or unrolled memcpy by optimization level (sangoku-mt4.5.3)

_2026-11-08 11:40:00_

## Context

Memory audit (`sangoku-mt4.5`). The user chose compact `memcpy` for `s`/`z`,
unrolled for `0`-`3`; this splits memset and memmove into separate objects too.

## Case

Any `memcpy` call; linking picks one body by optimization level.

## Currently emits

One `runtime/memory.asm` with `__gbc_memset` and a single `memcpy`/`memmove`
routine (SDCC-derived four-byte forward loop), linked at every level.
Before-sizes and cycles: not recorded.

## Should emit

`memcpy_size` (32 bytes) for `s`/`z`, `memcpy_opt` (57 bytes) for `0`-`3`; one
linked, no runtime dispatch, no tables or scratch RAM. T-cycles from entry
through `RET` (excludes caller setup/`CALL`/cleanup; src `$c400`, dst `$c600`):

```text
len     0    1    2    3    4    8   16    64    256
size  192  236  288  340  392  600 1016  3512  13496
opt   260  280  316  336  372  484  708  2052   7428
```

## How

Objects `memmove`, `memset`, `memcpy_size`, `memcpy_opt` (`src/link.rs`).
`memmove` keeps the overlap-safe algorithm. Both copies keep the split ABI,
destination return and caller-owned stack arguments, and clobber caller-saved
registers. Stack: 3 argument + 2 return + up to 6 saved/transient = 11 bytes.
`memcpy_size` is a zero-guarded byte loop equivalent to the supplied gbdev
example; `memcpy_opt` keeps the SDCC-derived loop (`runtime/NOTICE`; no vendored
sources changed).

`tests/memory.rs` checks both against a host model over zero, small/unroll and
255/256/257/511 lengths, both address orders, guards, return values, stack and
arguments; 40 random cases, seed `0x6d656d`. Reproduce the table with
`cargo nextest run --no-fail-fast -E 'binary(memory)' --success-output immediate`.
Default nextest 172 passed (17 profile exclusions); extensive
`upstream_u64_decimal_formatting_matches_host` passed; hello build passed, also
`--opt-level z`; clippy, fmt, LSP clean.

## Alternatives

Not done: the full copy/fill audit (caller costs, inline candidates, fill
comparisons) remains open.
