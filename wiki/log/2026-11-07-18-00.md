# Build core and programs with debug assertions off

_2026-11-07 18:00:00_

rustc_command now passes -Cdebug-assertions=off. At opt-level 0 rustc enables debug assertions, which also enables overflow checks and the ub_checks precondition_check functions; those pull panic paths through core and overflowed ROM0 on the primes.rs repro (get_unchecked(2..).iter().filter().count()). Tested on that repro: -Cpanic=abort, -Cpanic=immediate-abort, and either with -Coverflow-checks=off all fail with a ROM0 placement error; -Cdebug-assertions=off alone links and runs. immediate-abort and overflow-checks=off are not needed, and immediate-abort would bypass the \_\_gbc_panic handler, so it is left out. Consequence: overflow in user code wraps silently. build/core is not keyed on flags, so rm -rf build/core after changing them. The repro links but returns 48 instead of 15 and emits junk serial bytes; filed as a bug. examples/hello.rs and primes.rs updated to avoid formatting and panicking paths; ufmt added as a dev-dependency. No push.
