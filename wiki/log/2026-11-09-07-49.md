# Add selected optimization comparisons and improve Unicode casing (sangoku-7zf)

_2026-11-09 07:49:19_

## Context

Epic `sangoku-7zf` aimed to cut LR35902 code size and stack for upstream Unicode
casing (the five largest uppercase functions total 10,589 bytes; baseline 17,483
B retained at opt `z`, 2,106 data). Its last child, `sangoku-7zf.5`, was a
selected-case audit path to measure each change. Result: upper 17761 -> 17130 B,
lower 16074 -> 15413 B, with no Rust `core` changes.

## Case

Six volatile-input cases (62 samples) around
`char::to_uppercase`/`to_lowercase`, `CaseMappingIter`, and the expansion and
range binary searches.

## Currently emits

Per child baseline: `conversions::to_upper` 3333 B (frame 55), `to_lower` 2546
B; `CaseMappingIter::new` 1887 B (frame 132); verbose multi-byte comparisons,
materialized booleans and stack reloads; the search closure and
`select_unpredictable` as separate functions. Assembly listing not recorded.

## Should emit

Smaller `to_upper`/`to_lower`, iterator and search code. Actual: `to_upper` 3333
-> 2977 B (frame 55 -> 41), `to_lower` 2546 -> 2160 B, `CaseMappingIter::new`
1887 -> 1843 B (frame 132 -> 106). Data unchanged; all sampled paths faster;
casing peak stack -36 to -60 B, searches -16 B.

## How

- Added `audit-optimizations` and an extensive-only optimization test binary.
  Reports preserve sources, MIR/CLIF, ASM/maps, code/data and symbol sizes,
  cycles, peak stack and compiler provenance; comparisons reject incompatible
  sources/inputs and changing backends. Usage in `wiki/concepts/testing.md`.
- wasmtime `095708a5`: stream small non-overlapping copies (overlapping keeps
  load-all/store-all). Iterator 2994 -> 2957 B.
- wasmtime `3eee02f0`: `i32` comparisons as native `i16` ones.
- cg_clif `9f51c9e`: scalar `select_unpredictable` intrinsic. Each search -65 B
  (+63 B wrapper, -128 B fallback helpers) through one shared helper.
- Tests: all 60 core/lowered tests, full FileCheck, copy-order and report unit
  tests, hello smoke, clippy/fmt. Repeated snapshots reproduce identical
  metrics.
- Closed all remaining `7zf` children and the epic.

## Alternatives

Further optimization is possible; remaining children were all satisfied. Cold
parallel builds exposed an existing cache race; final serial checks pass and
warm tests remain bounded. Existing wasmtime dirty files preserved.
