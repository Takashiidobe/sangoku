# Play the bike-riding tune from Rust (sangoku-ais)

_2026-11-08 10:13:52_

## Context

`sangoku-ais` (feature, P1) asked for the Pokemon Red bike-riding score as a
standalone Rust example with pulse, wave and noise playback, resolving note
timing, frequencies, envelopes, vibrato and drum semantics from pret/pokered. It
exercises the compiler end to end on real audio code and runs in SameBoy.

## Case

A Rust APU player driven by typed score events (`examples/audio.rs`) playing the
complete user-supplied four-channel bike-riding score by writing APU registers
directly.

## Before

No audio ROM example existed.

## After

A standalone audio ROM: both pulse tracks, wave instrument 3, noise instrument
16, envelopes (including increasing ones), vibrato, original fractional-frame
tempo, perfect-pitch toggles and looping. The ROM builds at opt `0` and `z`. The
user listened in SameBoy and confirmed playback sounds good.

## How

Bounded nextest checks the note constraints and that all tracks have matching
introductions (13.5 frames) and loop durations (2052 frames). Usage and
attribution are in `wiki/concepts/audio.md`; README unchanged. Formatting,
clippy and LSP diagnostics pass. Closed `sangoku-ais`.
