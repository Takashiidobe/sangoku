# Bounded memory-offset address emission

sangoku-9uq: memory access base+30 was copying BC to HL, then executing
30 INC HL instructions. Both RGBDS printing and machine emission now use
LD HL, immediate; ADD HL, BC for offsets outside 0 and plus/minus one.
Those three offsets retain the smaller/faster copy and optional INC/DEC.
ISLE and register allocation constraints are unchanged: BC is the fixed base;
HL and A are already early-clobbered scratch registers for memory accesses.
The new sequence preserves BC, A and DE. Flags are internal to instructions;
no flags value is carried between these CLIF memory operations.

For offset +30, address setup drops from 32 to 4 instruction bytes and
248 to 20 T-cycles (copies included). These are instruction costs, not a
whole-program benchmark. Larger offsets wrap to 16 bits, avoiding output
whose size grows with a CLIF i32 offset.

Reproduce:

- cargo build -p sangoku-lower
- cargo +gbc-lr35902 build --release --manifest-path third_party/rustc_codegen_cranelift/Cargo.toml
- cargo nextest run --manifest-path third_party/wasmtime/cranelift/codegen/Cargo.toml --features lr35902 --no-fail-fast -E 'test(lr35902)'
- cargo nextest run --no-fail-fast -E 'test(memory_offsets)'
- cargo run -- asm examples/let_down.rs
- cargo run -- build examples/hello.rs build/hello.gb

The new bounded CLIF test checks 14 offsets (0, ±1, ±2, ±30, +300, -200,
32768, 65535, 65536, i32::MIN/MAX) with targets C0FF/C100, 16-bit loads and
stores, a live base after stores and SP restoration. Existing tests cover
8/16/32-bit loads/stores and extensions. Backend tests check emitted bytes
and compiled load/store sequences. No emulator changes were needed.

Regenerated default-opt let_down.asm: INC HL count falls from 2915 to 251;
longest consecutive run falls from 49 to 1. The old base+30 site now prints
LD HL, $001E; ADD HL, BC. There are 139 ADD HL, BC address calculations.
Validation: 38 focused backend tests and both memory-offset tests pass;
hello.gb smoke build succeeds. Cold standalone-lower recompilation makes the
first integration run slower; warm checks complete below 10 seconds.
Clippy --allow-dirty --fix, fmt, LSP diagnostics and diff checks pass.
