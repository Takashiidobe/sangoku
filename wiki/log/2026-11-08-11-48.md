# Select compact or unrolled move and fill helpers

_2026-11-08 11:48:54_

sangoku-mt4.5.4: Added independently selected size/opt variants for memmove
and __gbc_memset. s/z select byte loops; 0/1/2/3 select four-byte unrolling.
Only one variant per referenced helper is linked. No runtime dispatch or
cross-helper dependencies. Existing memcpy selection is unchanged.

memmove_size copies one byte per iteration in either direction; memmove_opt
unrolls both directions, preserving overlap semantics. memset_size retains the
existing byte loop; memset_opt keeps the value in A and uses auto-incrementing
HL stores. Both preserve the split ABI, return destination and caller arguments.

Unrolled loops adapt the existing SDCC-derived copy algorithm; source revision,
SHA-256 and license are retained in runtime/NOTICE. No vendored sources changed.
No variants own scratch RAM or tables. Peak helper saves: move 6 bytes in either
variant; fill 2 bytes for size, 4 for opt, excluding arguments/return address.

| Helper | Size ROM bytes | Opt ROM bytes |
| --- | --- | --- |
| memmove | 56 | 114 |
| memset | 24 | 43 |

T-cycles from helper entry through RET; excludes caller setup/CALL/cleanup.
Move source/destination differ by one byte at $c400/$c401. Fill starts at $c4ff.

| Length | Move forward size/opt | Move backward size/opt | Fill size/opt |
| --- | --- | --- | --- |
| 0 | 220/288 | 248/328 | 120/216 |
| 1 | 264/308 | 316/356 | 176/220 |
| 16 | 1044/736 | 1336/904 | 1016/408 |
| 256 | 13524/7456 | 17656/9544 | 14456/3288 |
| 1024 | 53460/28972 | 69880/37204 | 57464/12516 |

both directions, identical pointers, guards, returned pointers and untouched
stack arguments. Fill values: 0, 1, 0x37, 0x80, 0xfe, 0xff; copy seed: 0x6d656d.
