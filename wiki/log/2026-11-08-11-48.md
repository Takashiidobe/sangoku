# Select compact or unrolled move and fill helpers (sangoku-mt4.5.4)

_2026-11-08 11:48:54_

## Context

Follow-up to `sangoku-mt4.5.3` (audit `sangoku-mt4.5`): `memmove` and
`__gbc_memset` needed the same size/opt choice, selected independently.

## Case

A `memmove` or `__gbc_memset` call at any optimization level.

## Currently emits

One `memmove` and one `memset` body at every level. Before-sizes and cycles: not
recorded.

## Should emit

`s`/`z` link byte loops, `0`-`3` four-byte unrolling; one variant per referenced
helper, no runtime dispatch or cross-helper dependencies. ROM bytes size/opt:
`memmove` 56/114, `memset` 24/43. T-cycles, entry through `RET` (move src/dst
differ by one byte at `$c400`/`$c401`; fill starts at `$c4ff`):

```text
len   move fwd size/opt  move back size/opt  fill size/opt
0     220/288            248/328             120/216
1     264/308            316/356             176/220
16    1044/736           1336/904            1016/408
256   13524/7456         17656/9544          14456/3288
1024  53460/28972        69880/37204         57464/12516
```

## How

`memmove_size` copies a byte per iteration either way; `memmove_opt` unrolls
both directions, preserving overlap. `memset_size` is the existing byte loop;
`memset_opt` keeps the value in `A`, using auto-incrementing `HL` stores. Both
keep the split ABI, return the destination, preserve caller arguments, own no
scratch RAM or tables. Unrolled loops adapt the SDCC-derived copy
(`runtime/NOTICE`; no vendored sources changed). Peak saves: move 6 bytes; fill
2 (size), 4 (opt). Tests cover zero, unroll/page/counter boundaries through
1024, both overlap directions, identical pointers, guards, returned pointers,
untouched stack arguments; fill values 0, 1, 0x37, 0x80, 0xfe, 0xff; seed
`0x6d656d`. Linker tests check all six levels. Reproduce with
`cargo nextest run --no-fail-fast -E 'binary(memory)' --success-output immediate`.
Default nextest 174 passed (17 exclusions); extensive
`upstream_u64_decimal_formatting_matches_host` passed; hello build passed, also
`--opt-level z`; clippy, fmt, LSP clean.

## Alternatives

Not done: `memcpy` unchanged; broader audit epics (caller costs, inline
candidates, more reference implementations) remain open.
