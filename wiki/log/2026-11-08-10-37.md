# Share audio phrases with call and return (sangoku-z48)

_2026-11-08 10:37:55_

## Context

`sangoku-z48` (feature, P1): the supplied Pokemon Center score is built from
shared subroutines, and Bike Riding repeated expanded drum patterns. The player
needed `Event::Call` over static phrase slices with bounded return state,
preserving channel settings across calls, so the original structure could be
ported and the expanded events stay equivalent.

## Case

A score needs to reuse a phrase (a `&'static [Event]`) from several places and
resume the caller when the phrase ends.

## Before

No call support; Bike Riding drums were expanded inline.

## After

Pokemon Center runs with its original subroutines. Bike Riding drums use 19
calls to three shared patterns, and its expanded events are unchanged. Eight
bounded audio tests pass (return, nesting, empty phrases, local loops, stack
limit, song expansion, timing) and all three ROMs build at opt `0`/`z`. The user
confirmed playback.

## How

`Event::Call` with implicit return at phrase end and a bounded four-entry
position stack. Channel settings and fractional timing persist across calls;
loops are local to the current phrase. Const channel initialization avoids
repeated large startup construction. Added the requested README audio commands
and wiki guidance. Formatting, clippy, LSP diagnostics and whitespace checks
pass. Closed `sangoku-z48`.

## Alternatives

Bike Riding at opt `z` grows from 13769 to 14496 retained bytes. Enums remain
unpacked; packed encoding is a tracked follow-up.
