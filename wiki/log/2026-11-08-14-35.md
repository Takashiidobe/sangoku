# Organize independently selected runtime libraries

_2026-11-08_

sangoku-7u5: Move registered runtime routines into integer, bitshift, float
and memory directories. Family registries under src/runtime supply stable
object names, source paths and dependency text. Linkage selects size variants
at s/z, speed variants at 0/1/2/3, and common implementations at every level.
Native integer width paths use i8/i16/i32; existing wider support is retained.
No new native-width arithmetic algorithms or ABI changes are introduced.

Split udiv16/urem16 wrappers from the shared division core. Their combined
code remains 95 bytes with unchanged measured cycles; selecting either entry
now excludes the other wrapper. Assembly audit helpers combine the three
sources when they need to exercise both public entries.

Split the hand-written f32 library into separate operation and shared-helper
objects. Keep fallthrough labels together, export cross-object dependencies,
and use absolute jumps between independently placed sections. Shared macros
and scratch state remain common. Macro definitions are visible to dependency
discovery. Existing non-reentrant scratch behavior is unchanged.

A real Rust f32 addition ROM executes at opt 0/z and its map excludes multiply,
divide, square root, FMA, rounding and comparison entries. Existing float
reference tests exercise the aggregate; production linkage uses only selected
objects. Tests and generators use the new paths, and bundle packaging copies
nested assembly/includes. Generated float assembly was regenerated and checked.

Validation: 177 default nextest tests pass, 17 profile exclusions. Four affected
extensive tests pass: f16_fma_matches_reference,
f64_shared_runtime_matches_host, f128_shared_runtime_matches_reference and
wide_numeric_conversions_match_reference. Hello ROM build, cargo clippy
--allow-dirty --fix, cargo fmt, LSP error diagnostics and git diff --check pass.
No vendored compiler/backend sources changed.

Follow-up sangoku-rxd tracks separating operations behind f64/f128 and wide
conversion operation-code dispatchers. Existing native-width popcount work
remains sangoku-4gv. Follow-up sangoku-fx7 audits CLZ/popcount candidates
and whether they need wiring. Pre-existing local edits are preserved.
