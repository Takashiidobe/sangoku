# Migrate 16-bit multiplication

Replaced runtime/mul16.asm with the ABI-adapted MSB-first shift-and-add port.
Operands arrive in B/C (low/high) and A/[SP+2] (low/high); the result returns in
A/B (low/high). This fixes the previous operand byte-order defect. The helper
uses eight iterations when rhs < 256 and sixteen otherwise. Size is 30 bytes;
timing including RET is 480 + 4p or 848 + 4p clocks, where p is the rhs
population count. Closed sangoku-9ud.

Added tests/test_mul16.py to assemble the actual helper with RGBDS and execute
its bytes in a small instruction interpreter, not a full emulator. Verified
10,256 boundary, signed, asymmetric-byte, and random product pairs plus five
timing cases. README documents arithmetic support and the test command.

Passed: Python regression tests, Ruff checks/format, cargo test --bins, cargo
clippy --allow-dirty --fix, cargo fmt, and git diff --check. Passed ROM smoke:
cargo run -- build examples/blank.rs build/blank.gb. Plain cargo test fails
because the existing no_core example has no host main. No compiler or vendored
source changes; existing vendored warnings remain.
