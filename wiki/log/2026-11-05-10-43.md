# rustc_codegen_cranelift a1b1e35 — Localize jump labels for RGBDS

_2026-11-05 10:43:51_

## Context

Cranelift prints branch targets as `labelN`, but RGBDS needs symbols it can
resolve inside a section. Commit `a1b1e35` in `rustc_codegen_cranelift`; no
bead. It makes generated control flow assemble.

## Case

A function containing a jump and its target, e.g. `jr label1` with a `block1:`
label further down.

## Before

`src/rgbds.rs::localize_block_labels` only rewrote `blockN` into local `.blockN`
labels; `labelN` references passed through unchanged and did not match any
defined label.

## After

```text
block0:      ->  block0:
  jr label1  ->    jr .block1
block1:      ->  block1:
```

`labelN` becomes `.blockN`. The new `starts_label` check applies the same token
boundary rule as `starts_block`, so a longer symbol containing `label` is
preserved.

## How

`src/rgbds.rs` extended with `starts_label`, pushing `block` plus the digits.
Tests `writes_rgbds_functions_and_local_block_labels` (now feeds `jr label1`)
and `emitted_source_assembles_with_rgbasm` (now has a `jp label1`) assemble the
result with RGBDS.

## Alternatives

Global labels would collide across generated functions and codegen units. Local
labels scope generated control flow to its function/section.
