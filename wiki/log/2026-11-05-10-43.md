# rustc_codegen_cranelift a1b1e35 — Localize jump labels for RGBDS

_2026-11-05 10:43:51_

## Files and implementation

`third_party/rustc_codegen_cranelift/src/rgbds.rs` rewrites Cranelift's `labelN`
references into RGBDS local block labels. It recognizes the token boundary
before rewriting, so a longer symbol containing `label` is preserved:

```diff
+if starts_label {
+    localized.push_str("block");
+    localized.push_str(&line[digits_start..digits_end]);
+}
```

The implementation chose local labels to avoid collisions among generated
functions/codegen units. Tests assemble a function containing a jump and its
label with RGBDS.

Commit: `a1b1e35` — `rustc_codegen_cranelift`.

- Purpose: Make generated Cranelift labels assemble correctly inside RGBDS
  sections. Change: Convert `labelN` references to local `.blockN` labels while
  preserving existing block labels. Implementation: Extended the RGBDS source
  rewriter to recognize label tokens and normalize them to the block-label form;
  updated assembly tests. Alternative: Global labels risk collisions across
  codegen units. Local labels scope generated control flow to its
  function/section.
