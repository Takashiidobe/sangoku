# Close the shifts and rotates audit

Audit sangoku-mt4.4, correctness sangoku-mt4.4.1 and decision sangoku-mt4.4.2.
Decisions, measurements and reproduction: wiki/audits/shifts.md and shifts.csv.
Implementation: sangoku-9tk for constants; sangoku-clp for variable helpers.
No production backend/runtime implementation changes in this audit.

Select byte moves plus short residual operations for constant shifts/rotates;
ADD HL,HL wins for 16-bit left counts 2..7. Keep zero-count identity. Adopt
compact bit loops for variable size/unoptimized builds, byte-chunk loops for
speed. Keep tiny constants inline; use the measured sharing break-even for
larger helpers. All ten operation/width combinations have explicit decisions.

Source snapshots, ABI adapters, C/Rust/CLIF probes and provenance are retained
under tests/fixtures/shifts. SDCC 4.6.4 r17147 clean gen.c SHA256 and commands
are recorded in provenance.json. JSON reports also retain commands, source
hashes, exact values, clobber observations and assembled artifacts. Current
compiler bytecode is checked against assembly. Unsupported operations use the
explicit repeated-bit reference rather than claiming existing compiler support.

Historical command: cargo run --example audit-shifts -- --full --samples 128
--seed 0 --exhaustive16 --output build/shift-audit/results.json --csv
wiki/audits/shifts.csv. Zero errors: 2204465 candidate, 5242880 exhaustive
constant-16 and 47424 compiler executions. This broad run was already complete;
it was not repeated at closure. Means in the report weight legal counts equally.

Reduced default command: cargo run --example audit-shifts -- --artifacts
build/shift-audit-fast --output build/shift-audit-fast/results.json. Zero errors:
1968 candidate, 252 compiler and 72 Rust executions. The Rust probes test normal
shifts and checked payload/validity guards, including wide invalid counts;
full Option ABI is not claimed. Defaults use four counts and six values,
shortlisted variants and body/caller modes. Exhaustive checks require explicit
--full --exhaustive16. Shift regression time dropped from about 39s to 1.2s.

Tests cover negative inputs, count masking, live inputs, SP restoration,
return frames and stack-bounded writes. Independent SRA and auto-indexed HL
regressions cover flags, timing and wraparound. Flat-memory instruction subset
only: no hardware peripherals, banking or interrupt timing.

cargo test --workspace: 63 tests pass, about 2.3s execution across suites.
cargo clippy --workspace --all-targets --allow-dirty --fix and cargo fmt --all
run; blank ROM smoke via cargo run -- build examples/blank.rs build/blank.gb
passes with existing vendored compiler warnings. Unrelated submodule, Beads
JSONL and popcount C formatting changes remain outside the audit commit.
