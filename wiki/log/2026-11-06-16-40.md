# Close the shifts and rotates audit (sangoku-mt4.4)

_2026-11-06 16:40_

## Context

Audit `sangoku-mt4.4`, correctness `sangoku-mt4.4.1`, decision
`sangoku-mt4.4.2`. The SM83 has only 1-bit shifts and rotates, so a 16/32-bit or
variable shift is either a long unrolled sequence or a loop; with a 32 KB ROM we
had to decide inline versus helper by count and width. Decisions, numbers and
reproduction: `wiki/audits/shifts.md` and `shifts.csv`. Implementation follows
in `sangoku-9tk` (constants) and `sangoku-clp` (variable helpers). No production
backend/runtime changes in this audit.

## Case

Constant and variable shifts/rotates (`ishl`/`ushr`/`sshr`/`rotl`/`rotr`) at 16
and 32 bits.

## Currently emits

Baseline is the `ShiftLeft16`/`ShiftRight16`/`ShiftRight32` emission; listing
not recorded here.

## Should emit

Constant shifts/rotates: byte moves plus short residual operations; `ADD HL,HL`
wins for 16-bit left counts 2..7. Keep zero-count identity. Variable counts:
compact bit loops for size/unoptimized builds, byte-chunk loops for speed. Tiny
constants stay inline; larger helpers use the measured sharing break-even. All
ten operation/width combinations have explicit decisions.

## How

- Source snapshots, ABI adapters, C/Rust/CLIF probes and provenance are under
  `tests/fixtures/shifts`; SDCC 4.6.4 r17147 clean `gen.c` SHA256 and commands
  are in `provenance.json`. JSON reports keep commands, hashes, values, clobber
  observations and assembled artifacts. Current compiler bytecode is checked
  against assembly. Unsupported operations use an explicit repeated-bit
  reference rather than claiming compiler support.
- Historical full run (already complete, not repeated at closure): zero errors
  over 2204465 candidate, 5242880 exhaustive constant-16 and 47424 compiler
  executions. Means weight legal counts equally.

```text
cargo run --example audit-shifts -- --full --samples 128 --seed 0 \
  --exhaustive16 --output build/shift-audit/results.json \
  --csv wiki/audits/shifts.csv
cargo run --example audit-shifts -- --artifacts build/shift-audit-fast \
  --output build/shift-audit-fast/results.json
```

- Reduced default: zero errors over 1968 candidate, 252 compiler and 72 Rust
  executions. Rust probes test normal shifts and checked payload/validity
  guards, including wide invalid counts; full `Option` ABI is not claimed.
  Defaults use four counts and six values, shortlisted variants and body/caller
  modes; exhaustive needs `--full --exhaustive16`. Shift regression time dropped
  from about 39s to 1.2s.
- Tests cover negative inputs, count masking, live inputs, SP restoration,
  return frames and stack-bounded writes; independent SRA and auto-indexed `HL`
  regressions cover flags, timing and wraparound.
- `cargo test --workspace`: 63 tests, about 2.3s. Clippy
  (`--workspace --all-targets`), `cargo fmt --all` run; blank ROM smoke passes
  with existing vendored warnings.

## Alternatives

Flat-memory instruction subset only: no hardware peripherals, banking or
interrupt timing. Unrelated submodule, Beads JSONL and popcount C formatting
changes remain outside the audit commit.
