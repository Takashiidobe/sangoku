## Files and implementation

The scaffold adds `cranelift/codegen/src/isa/z80/abi.rs`, `inst/`, `sdcc.rs`,
and `lower/`; `meta/src/isle.rs` registers generated lowering rules. The ABI
starts with an 8-bit word and leaves argument allocation incomplete:

```diff
+fn word_bits() -> u32 { 8 }
```

`sdcc.rs` records candidate Z80/SM83 conventions, but the lowerer and emitter
are still scaffolding. These pieces supplied a structure to port later; they did
not implement rustc's eventual C or Rust ABI.
