## Files and implementation

`cranelift/codegen/src/isa/lr35902/lower.rs` handles `Opcode::SymbolValue` when
the result is I16. `inst/emit.rs` loads the relocatable address into HL and
copies its bytes to the allocated result registers:

```diff
+sink.put1(0x21); // ld hl, imm16
+let reloc_offset = sink.cur_offset();
+sink.put2(0);
+sink.add_reloc_at_offset(reloc_offset, Reloc::Abs2, name, *offset);
```

The absolute 16-bit relocation is resolved by the downstream assembler/linker.
The lowerer extracts the symbol and addend from `GlobalValueData::Symbol`. This
supports function/data addresses required by generated library code while
staying within the Game Boy address width.
