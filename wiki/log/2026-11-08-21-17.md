# Expose pre-link assembly output (sangoku-meg)

_2026-11-08 21:17_

## Context

There was no way to see the compiler's RGBDS assembly without also running
`rgbasm`/`rgblink`/`rgbfix`. `sangoku-meg` (P2, feature) asked for
`sangoku asm source.rs [output.asm|-]` that reuses the existing compiler setup
and build options, stops before RGBDS, and is documented and validated for file
and stdout output.

## Case

`sangoku asm examples/hello.rs` and `sangoku asm examples/hello.rs -`.

## Before

No `asm` command; CLIF emission and full `build` were the existing paths. Not
recorded beyond that.

## After

The default output is `build/<stem>.asm`; `-` writes to stdout. `--opt-level`
and `--alloc` use the existing build parser. The output holds compiler-generated
RGBDS sections and external helper references, before runtime/library selection
and ROM placement. Default file and stdout assembly match byte-for-byte.

## How

`src/main.rs` shares compiler setup with CLIF emission and stops before RGBDS.
Usage examples are in `wiki/concepts/building-roms.md`.

Validation:

```text
cargo run -- asm examples/hello.rs build/hello.asm --opt-level z
cargo nextest run --no-fail-fast -E 'binary(sangoku) & test(tests::)'
target/debug/sangoku asm examples/hello.rs
target/debug/sangoku asm examples/hello.rs -
target/debug/sangoku clif examples/hello.rs -
```

All 22 CLI tests pass. The final three commands pass with failing
`rgbasm`/`rgblink`/`rgbfix` stubs first on `PATH`; none of those tools is
invoked. Existing CLIF output still contains functions. Clippy
`--allow-dirty --fix`, fmt, LSP diagnostics and diff checks pass.

## Alternatives

None recorded.
