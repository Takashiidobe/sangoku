# Expose pre-link assembly output

sangoku-meg adds `sangoku asm source.rs [output.asm|-]`, sharing compiler
setup with CLIF emission and stopping before RGBDS. The default output is
`build/<stem>.asm`; `--opt-level` and `--alloc` use the existing build parser.
The output contains compiler-generated RGBDS sections and external helper
references, before runtime/library selection and ROM placement.

Validation:

- cargo run -- asm examples/hello.rs build/hello.asm --opt-level z
- cargo nextest run --no-fail-fast -E 'binary(sangoku) & test(tests::)'
- target/debug/sangoku asm examples/hello.rs
- target/debug/sangoku asm examples/hello.rs -
- target/debug/sangoku clif examples/hello.rs -

All 22 CLI tests pass. Default file and stdout assembly match byte-for-byte.
The final three commands pass with failing rgbasm/rgblink/rgbfix stubs first
on PATH; none of those tools is invoked. Existing CLIF output still contains
functions. Clippy --allow-dirty --fix, fmt, LSP diagnostics and diff checks pass.
Usage examples are in wiki/concepts/building-roms.md.
