# Native signed division and remainder helpers

sangoku-mt4.8 and .1/.2: user replaced the extensive audit with bounded
implementation and Cranelift integration. No SDCC comparison or winner claim.
New i8 wrappers share an eight-step restoring magnitude core; i16 wrappers
share the existing unsigned core. i32 retains its existing frame helpers.
All use native typed libcalls, RGBDS and module symbol mappings, and runtime
object discovery. Narrow i32 widening and inline overflow checks are removed.

| Width | Pair + core ROM | Helper cycles, 7/3 div; rem | Rust caller cycles | Peak stack |
| --- | --- | --- | --- | --- |
| i8 | 83 | 556; 540 | 596; 580 | 6 |
| i16 | 176 | 1196; 1192 | 1340; 1336 | 7 |
| i32 | 421 | 20064; 20012 | 20560; 20508 | 25 |

T-cycles include RET; Rust caller includes argument setup, CALL, cleanup and
outer RET, excluding an outer CALL. Peak stack is the maximum over direct
and Rust probes including trap RST pushes; excludes the outer return address
and incoming stack arguments. No tables or owned scratch RAM. All public
registers and flags may be clobbered. Caller stack arguments are preserved.
Both signed entries share one core; i16 also shares with unsigned entries.
These are bounded observations, not best/worst or performance comparisons.

Tests: tests/signed_division.rs; Rust fixture under fixtures/signed-division.
Each width has 17 boundary/sign/trap pairs and eight LCG pairs (seed
0x81497623; multiplier 1664525; increment 1013904223). Four sign combinations,
MIN/MAX, MIN/-1, MIN/MIN, zero divisors and zero dividends are represented.
Host i64 division supplies truncation-toward-zero expectations. Direct helpers
and CLIF test trap/overflow semantics; unsafe Rust intrinsics skip undefined
inputs. Rust probes at 0/z assert each exact-width helper call and execute
valid cases. Checks include SP restoration, unchanged arguments and writes
restricted to the stack. No emulator extensions were needed.

Reproduce:
- cargo build -p sangoku-lower
- cargo +gbc-lr35902 build --release --manifest-path third_party/rustc_codegen_cranelift/Cargo.toml
- cargo nextest run --no-fail-fast --success-output immediate -E 'binary(signed_division) | test(signed_division_overflow_and_remainder_follow_clif) | test(link::tests)'
- cargo run -- build examples/hello.rs build/hello.gb

Decision: adopt native i8/i16 sdiv/srem helpers to avoid wider frame work;
retain i32 sdiv/srem. This is an implementation decision, not an SDCC audit.

Validation: 18 focused helper/linkage tests and 40 backend tests pass. Hello
ROM smoke build passes. Clippy --allow-dirty --fix, fmt, LSP diagnostics and
diff checks pass. An unrelated slow core test selected by a broad filter was
stopped; final checks use the bounded filter above.
