# Cranelift 43f09482 — Put LR35902 byte registers in regalloc

_2026-11-05 09:02:15_

## Context

The LR35902 has seven usable 8-bit registers (`B C D E H L A`) and 16-bit
operations work on pairs. Cranelift's `regalloc2` must be told which registers
exist, and moves and spills must be real instructions, otherwise generated code
cannot safely take part in register allocation. Commit `43f09482` (Cranelift
fork, `third_party/wasmtime`) does that. No bead id is recorded.

## Case

Register moves were placeholders, with no operand uses/defs and no allocatable
set.

## Before

No allocatable register set and no modeled move instruction.

## After

The allocator sees only the seven real byte registers:

```rust
pub(crate) const fn allocatable_int_regs() -> PRegSet {
    PRegSet::empty().with(preg(Gpr8::B)).with(preg(Gpr8::C))
        .with(preg(Gpr8::D)).with(preg(Gpr8::E))
        .with(preg(Gpr8::H)).with(preg(Gpr8::L)).with(preg(Gpr8::A))
}
// Inst::Move8 { dst, src } => emit_ld_r_r(sink, hw_enc(dst.to_reg()), hw_enc(*src))
```

A test checks the `LD A,B` encoding (`0x78`).

## How

Files: `isa/lr35902/inst/regs.rs`, `abi.rs`, `inst/mod.rs`, `inst/emit.rs`.
Mapped B, C, D, E, H, L and A to physical registers; added `Move8`, dummy uses,
operand collection, and one-byte spill slots (the ABI assigns one spill slot per
integer byte), with allocator tests.

## Alternatives

Pair operations must coordinate component bytes, so the allocator receives byte
registers rather than fictitious general 16-bit registers.
