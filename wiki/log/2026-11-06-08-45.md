# Add RGBDS macro support to asm-lsp

_2026-11-06 08:45:48_

Bookkeeping, tooling. The runtime division routines are macro-heavy RGBDS
assembly, which the `sm83` support from the previous log did not understand.

Added `assembler = "rgbds"` to `~/asm-lsp` and selected it in sangoku
`.asm-lsp.toml`. A source index recognizes modern and legacy macro definitions,
scoped local and unique labels, and calls inside `REPT` blocks. Connected macro
body hover, definition navigation, references, completion and document outlines;
added `MACRO`/`ENDM`/`REPT`/`ENDR` directive docs. Indexing uses current buffer
contents and ignores comments and quoted strings. Added a division-macro fixture
and seven regression tests.

All 153 tests passed; Clippy and formatting checks passed with existing
warnings. Reinstalled `~/.cargo/bin/asm-lsp` and verified all macro features
plus SM83 instruction hover in headless Neovim on `runtime/udiv16alt.asm`.
Unsaved macro name changes update hover and completion. Not done: scope is the
current file; `INCLUDE` traversal and macro expansion are not implemented.
