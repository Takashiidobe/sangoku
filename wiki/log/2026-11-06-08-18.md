# Try RGBDS language server

_2026-11-06 08:18:44_

Bookkeeping, tooling trial. Assembly in `runtime/` and `rom/` had no editor
support, so I tried an RGBDS language server.

Installed `@minorum/rgbds-language-server` 0.1.4 globally and built its native
parser dependencies. Added project Codex LSP configuration for `.asm` and
`.sm83` files. Verified document symbols, scoped local-label definitions,
references, rename preparation and diagnostics through the connected LSP client.
`runtime/mul16.asm` has no diagnostics; `rom/header.asm` warns about the
externally generated `__rust_gbc_main` symbol.

Found that upstream Linux file URI handling strips the leading slash, preventing
normal workspace indexing, so cross references into unopened files are
unreliable. `cargo clippy --allow-dirty --fix` and `cargo fmt` passed. No
compiler or vendored sources changed.
