# Audit intrinsic lowering and call routes (sangoku-57q.6)

_2026-11-08 09:44:03_

## Context

sangoku-57q.6 (P0) asked to map the intrinsics `core` needs (`ctpop`, `ctlz`,
`bswap`, rotate, saturating, ...) to supported CLIF ops or libcalls, and to
audit which are used and which are unimplemented on this target. This change is
the source-driven audit and the follow-up split; it closed the bead with no
backend changes.

## Case

339 explicit integer, float and memory intrinsic probes compiled and lowered
through cached `core`/`compiler_builtins`.

## Currently emits

Representative coverage only: `core-intrinsics.rs` snapshotted and executed
`u32` `count_ones`/`leading_zeros`/`trailing_zeros`/`swap_bytes`/`rotate_left`/
`reverse_bits` plus `u16` saturating add/sub. No complete used-intrinsics
inventory or all-width audit.

## Should emit

A checked baseline of lowering status, terminal callees and reachable Rust
functions. Whole core survey: 3184 core + 2043 builtins + 921 generic-driver
functions, zero failures and zero undefined symbols.

## How

- `tools/intrinsics_audit.py`, `tests/coverage/intrinsics.tsv`, and routes and
  limits documented in `wiki/intrinsics.md`. The audit matrix is in the
  extensive nextest profile.
- Installed rust-analyzer on the pinned nightly and verified LSP navigation.
- Existing wide-operation tickets (wide shifts, multiplication, float) now carry
  route evidence.
- Verification: all 160 default tests and the extensive intrinsic test pass;
  clippy, fmt, Ruff and LSP diagnostics pass.

## Alternatives

The audit is not a guarantee that arbitrary generic instantiations or
unsupported libm endpoints can link. Follow-ups created: sangoku-57q.10.4
(narrow bit methods), sangoku-57q.10.5 (carryless multiplication), sangoku-9bq.1
(separate memory fill object). Closed sangoku-57q.6.
