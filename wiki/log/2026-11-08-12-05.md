# Bounded copy-fill and move-compare audits (sangoku-mt4.5, sangoku-mt4.6)

_2026-11-08 12:05:27_

## Context

`mt4.5` (copy/fill audit) closed on logs 11-40, 11-48 and 11-58: retain the
size/opt copy/fill helpers and the current inline policy. `mt4.6` (overlap-safe
move and memory compare) uses the same reduced scope: retain move variants,
compare the existing `compiler-builtins` `memcmp` against simple SM83 candidates
and equality. `memcmp` does exist in `compiler-builtins`; stale wiki claims that
it was missing are corrected. Reproduce with
`cargo run --example audit-move-compare`: it refreshes the `z` toolchain
libraries with a hello ROM build, lowers bounded callers and saves assembly,
maps, exact hashes, tool versions, backend revisions, SDCC reference hashes and
results under `build/move-compare/`.

## Case

`memcmp`/`memmove` callers. Lengths 0/1/4/16/256 cover equality,
first/middle/last mismatch, both unsigned directions at 0/255 and 127/128, and
opposite later mismatches; moves cover same pointers, forward/backward overlap
and non-overlap. 586 checks passed, including memory guards, source bytes, stack
restoration, caller-owned arguments, `i32` comparison result sign and move
pointer returns. No new emulator instructions were needed; `tests/memory.rs`
adds boundaries to 1024.

## Currently emits

`compiler-builtins` `memcmp`: ROM 327, body eq16 13576, caller eq16 13800,
caller first-mismatch16 1908, stack 27 (T-cycles; caller includes setup, spills,
`CALL`/`RET`, cleanup and outer `RET`, excluding the common outer `CALL`; stack
includes the outer return address and all arguments).

## Should emit

Same columns (ROM, body eq16, caller eq16, caller first-mismatch16, stack):
compact candidate 48, 1388, 1612, 436, 11; unrolled candidate 89, 956, 1180,
500, 11.

Ordering callers occupy 30 ROM bytes; equality-via-`memcmp` callers 117. No
tables or owned scratch RAM; all registers are caller-saved. At 16 equal bytes
inline i16-chunk equality costs 4464 T / 747 ROM / 72 stack, versus 1976/1544 T
for compact/unrolled equality callers plus shared helper ROM; this inline
candidate does not redefine Rust `raw_eq` lowering policy. Move callers at 256
bytes: compact 13748/17880 T forward/backward, unrolled 7680/9768; caller ROM
30, helper ROM 56/114, stack 13, no tables/scratch RAM.

## How

Candidates in `tests/fixtures/audit/` are independent byte loops and four-byte
unrolling with early mismatch exits, returning -1/0/+1 as signed `i32` in
`A`/`B`/`C`/`D`. SDCC `device/lib/memcmp.c` confirms the unsigned-byte and
first-mismatch contract; `device/lib/memmove.c` and `z80-common/memmove.s`
confirm copy-direction logic (Z80 `LDIR`/`LDDR` are not executable SM83
candidates). Validation: 174 default nextest tests passed;
`cargo clippy --allow-dirty --fix` (including the example), `cargo fmt`, LSP
diagnostics and `git diff --check` pass.

## Alternatives

Decisions: `memmove` Replace: NO, retain size/opt helpers. `memcmp` Replace:
YES, compact for size and unrolled for speed; migration tracked in
sangoku-mt4.11. Equality specialization Replace: NO; retain the existing policy
until that migration.
