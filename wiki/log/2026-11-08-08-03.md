# Split wide32 into individually linked runtime helpers (sangoku-bov)

_2026-11-08 08:03:20_

## Context

The monolithic `wide32` runtime linked as one 1066-byte unit whenever any helper
was used. sangoku-bov (P2) splits it so `shift8` or a single unary helper does
not retain unrelated code. Result: `shift8` retained sections 2270 -> 1251.

## Case

One 32-bit helper: `shift8`, `popcnt32`, `mul32` or unsigned div/rem.

## Currently emits

Any helper pulled in all of `wide32.asm` (1066 bytes).

## Should emit

Only the selected objects. Selected runtime bytes: `shift8` 47; `popcnt32` 58;
`mul32` 108; unsigned division + remainder + shared kernel 246. Retained ROM
section bytes, same probes at opt 0:

```text
probe             before  after
shift8              2270   1251
popcnt32            1796    788
mul32               1917    959
unsigned div/rem    2342   1522
```

Empty stays 95; ROMs stay padded to 32768. The full split runtime is still 1066
bytes.

## How

- 12 independently selected objects: multiplication, four unary bit helpers,
  8/16-bit shifts and the division/remainder wrappers, which share `div32_core`
  through external symbols and guarded assembly macros. `wide32.asm` remains an
  include-only entry for existing harnesses.
- Runtime selection follows unresolved exports to a fixed point, including
  dependencies of selected runtime sources. Program definitions override it;
  heap startup and mangled panic roots keep their objects. Assembly uses the
  runtime root as an include path; bundles include `.inc` files.
- Tests: volatile-input `shift8`, `popcnt32`, `mul32` ROM probes (three inputs
  each, no unrelated helpers); the unsigned div/rem ROM checks shared-kernel
  selection and no signed wrappers. 155 default tests pass in 8.765s; extensive
  `scalar_integer_gaps_match_host` in 3.505s. Hello links; Python syntax,
  Clippy, fmt, LSP, diff checks pass.

## Alternatives

The relocated runtime objects and compatibility entry assemble outside the
repository. No `third_party` changes, no push.
