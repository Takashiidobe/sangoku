# i32 mul/div/rem and bit ops (sangoku-7qz.2, sangoku-7qz.5)

_2026-11-07 00:20_

## Context

`i32` `imul`/`udiv`/`urem`/`sdiv`/`srem` and `popcnt`/`clz`/`ctz`/`bitrev`/
`bswap` were unsupported, as were `i8`/`i16` forms where missing. The Game Boy
has no multiply or divide, so these must be runtime routines. sangoku-7qz.2 and
.5 (P0) asked for libcalls reusing the `GbcMul16`/`Udiv16`/`Urem16` pattern,
with emulator regressions against host results (0, 1, MAX, MIN, sign mixes) and
division traps per CLIF semantics.

## Case

`a * b`, `a / b`, `a % b`, `count_ones()`, `leading_zeros()` etc. on `u32`/`i32`
and narrower signed/bit ops.

## Before

Unsupported in the matrix. Exact diagnostics: not recorded.

## After

All lower via libcalls into the new `runtime/wide32.asm`.

## How

- `mul32`, `udiv32`/`urem32` (shared restoring core), `sdiv32`/`srem32` (sign
  wrappers; zero divisor and MIN/-1 for `sdiv` trap via `rst $10`), `popcnt32`/
  `clz32`/`ctz32`/`bitrev32`. Linked by `sangoku build` and the lowered tests.
- New LibCalls `GbcMul32`/`Udiv32`/`Urem32`/`Sdiv32`/`Srem32`/`Popcnt32`/
  `Clz32`/`Ctz32`/`Bitrev32`; the rgbds libcall map now also has `Urem16` (was
  missing).
- `call_libcall`/`widen`/`low_bytes` helpers replace three copy-pasted call
  blocks. `i8` mul/div widen to `i16` helpers; `i8`/`i16` `sdiv`/`srem` and all
  narrow bit ops widen to the `i32` helpers (`clz` subtracts the pad, `ctz` sets
  a sentinel bit, `bitrev` takes the top bytes). `bswap` `i32` is inline byte
  moves.
- Latent bug fixed: libcalls never reserved outgoing stack-arg space
  (`accumulate_outgoing_args_size`), so a stack argument overwrote the
  function's return address when it had no spill frame. The old `mul16`/`udiv16`
  blocks had it too.
- The emulator gained `set`/`res` and `ld a,[bc]`/`[de]` (`tests/emu.rs`).
- Tests: `lowered.rs` `wide_arithmetic_and_bit_ops_match_host` (edges + seeded
  samples at `i8`/`i16`/`i32`) and `division_traps_reach_the_rst_vector`.

## Alternatives

Gaps filed: `i8`/`i16` `sdiv`/`srem` do not trap on MIN/-1; `cls` unsupported.
