# 7qz.3: sign extension

- New `SignFill8` inst: `ld a, src; add a, a; sbc a, a; ld dst, a` (0xFF if bit 7 set, else 0). Clobbers A.
- `sextend` i8->i16/i32 and i16->i32 copy the source bytes, sign-fill the first extra byte and copy it into any remaining ones.
- `sload8`/`sload16` reuse the load arm with the same fill.
- Test: tests/lowered.rs `sign_extension_matches_host` (boundary values, incl. sload at offset 300). Note the first i8 arg is in B.
- Matrix: sextend and sload\* ok for i8/i16/i32; i64/i128 stay with 7qz.9.
