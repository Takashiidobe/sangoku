# Audit unsigned 16-bit division

Completed sangoku-mt4.2 and correctness/measurement children from base 44d358c.
Detailed decisions and tables: wiki/audits/division16.md; all class/operation
measurements: wiki/audits/division16.csv. Runtime/compiler sources unchanged.

Replace q/r: YES, compact SDCC Z80-derived SM83 port, 95 bytes for both entries.
The existing incorrect object is 97 bytes. Implementation: sangoku-88j. Shared
divmod: YES; paired-operation lowering/exposure: sangoku-yz4. Default early
exits: NO; keep the tested alternative (+38 bytes, slower narrow median)
available for workloads that justify its much faster special cases. SDCC's
native SM83 loop and restoring unroll variants lose the default tradeoff.

Seven correct fixtures cover repaired rolled, 4x/16x unrolled, early-exit, SDCC
SM83, Z80-derived SM83, and Z80-derived plus early exits. Shared wrappers
normalize our ABI and return A/B, or quotient A/B plus remainder C/D. SDCC
source revisions/hashes are in tests/fixtures/division/provenance.json; original
notices and GPL/exception text are retained alongside the fixtures.

The full audit passed 309,985 executions: 25,543 ordinary runs per variant, 16
zero-divisor runs per variant, and all 65,536 eight-bit input pairs for each
Z80-derived port. Inputs include boundary pairs, equal/smaller dividends, powers
of two and narrow/wide random divisors (1,024 per class, seed 0). Host divmod,
algebraic identity, remainder bounds, ABI, SP and write bounds are checked.
Frozen baseline q(1,1) returns 256; remainder uses uninitialized state; the old
alternate fails linking its quotient-local .divide label.

Selected port: narrow quotient caller 1236 clocks; wide class mean 1133.3,
median 1136, with 6 peak stack bytes and zero scratch/table bytes. Shared divmod
caller median 1144 versus 2324 for two calls; 22 versus 51 caller bytes, 6
versus 8 stack bytes. The extra combined wrapper costs 14 helper bytes.

Commands: python -B -m unittest discover -s tests -v python -B
tests/audit_division.py --samples 1024 --seed 0 --exhaustive8 --output
build/division-audit/results.json --artifacts build/division-audit/artifacts
--csv wiki/audits/division16.csv Retained artifacts include sources, hashes,
objects, ROMs, symbols, maps, commands and tools versions; the failing alternate
also retains build-error.txt. Independent q/r-only links and the current CLI
smoke verify the 95-byte size.

All 40 unit tests, Ruff checks/format, cargo clippy --allow-dirty --fix, cargo
fmt, cargo test --bins and git diff --check pass. Measurements use flat memory
and synthetic callers; no hardware/peripheral or 32-bit verdict claimed.
