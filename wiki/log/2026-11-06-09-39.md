# Audit unsigned 16-bit division (sangoku-mt4.2)

_2026-11-06 09:39_

## Context

`sangoku-mt4.2` and its correctness/measurement children, from base 44d358c. The
harness (`sangoku-mt4.1`) showed the existing `udiv16`/`urem16` were wrong
(`q(1,1)` returned 256, remainder read uninitialized state), and division is
needed by Rust `core`. Before spending ROM bytes we compared candidates against
SDCC's. Detailed decisions: `wiki/audits/division16.md`; all measurements:
`wiki/audits/division16.csv`. Runtime/compiler sources unchanged.

## Case

16-bit unsigned quotient, remainder and divmod: rolled and unrolled restoring
loops, early exits, SDCC SM83 and Z80-derived ports.

## Before

Frozen baseline: `q(1,1)` returns 256; remainder uses uninitialized state; the
old alternate fails linking its quotient-local `.divide` label. The existing
incorrect object is 97 bytes.

## After

Replace q/r: YES, compact SDCC Z80-derived SM83 port, 95 bytes for both entries
(implementation: `sangoku-88j`). Shared divmod: YES; paired-operation
lowering/exposure: `sangoku-yz4`. Default early exits: NO; keep the tested
alternative (+38 bytes, slower narrow median) for workloads that justify its
much faster special cases. SDCC's native SM83 loop and restoring unroll variants
lose the default tradeoff.

Selected port: narrow quotient caller 1236 clocks; wide class mean 1133.3,
median 1136, with 6 peak stack bytes and zero scratch/table bytes. Shared divmod
caller median 1144 versus 2324 for two calls; 22 versus 51 caller bytes, 6
versus 8 stack bytes. The extra combined wrapper costs 14 helper bytes.

## How

Seven correct fixtures: repaired rolled, 4x/16x unrolled, early-exit, SDCC SM83,
Z80-derived SM83, and Z80-derived plus early exits. Shared wrappers normalize
our ABI and return `A`/`B`, or quotient `A`/`B` plus remainder `C`/`D`. SDCC
source revisions/hashes are in `tests/fixtures/division/provenance.json`;
original notices and GPL/exception text are retained with the fixtures.

The audit passed 309,985 executions: 25,543 ordinary runs per variant, 16
zero-divisor runs per variant, and all 65,536 eight-bit input pairs for each
Z80-derived port. Inputs include boundary pairs, equal/smaller dividends, powers
of two and narrow/wide random divisors (1,024 per class, seed 0). Host divmod,
algebraic identity, remainder bounds, ABI, SP and write bounds are checked.

```text
python -B -m unittest discover -s tests -v
python -B tests/audit_division.py --samples 1024 --seed 0 --exhaustive8 \
  --output build/division-audit/results.json \
  --artifacts build/division-audit/artifacts --csv wiki/audits/division16.csv
```

Retained artifacts include sources, hashes, objects, ROMs, symbols, maps,
commands and tool versions; the failing alternate also retains
`build-error.txt`. Independent q/r-only links and the CLI smoke verify 95 bytes.
All 40 unit tests, Ruff, `cargo clippy --allow-dirty --fix`, `cargo fmt`,
`cargo test --bins` and `git diff --check` pass.

## Alternatives

Measurements use flat memory and synthetic callers; no hardware/peripheral or
32-bit verdict is claimed.
