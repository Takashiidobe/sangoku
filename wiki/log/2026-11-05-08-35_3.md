# Cranelift 27e4b2ce — Add the first Z80 lowering template

_2026-11-05 08:35:52_

## Context

With the backend structure in place (`4515f1de`), Cranelift IR still had no path
into it. Commit `27e4b2ce` (Cranelift fork, `third_party/wasmtime`) connects
CLIF instruction selection to the machine-instruction scaffold. No bead id is
recorded.

## Case

Any CLIF function reaching the backend had no `LowerBackend` implementation.

## Before

`lower.rs` held one line and `lower/isle.rs` was a stub.

## After

`isa/z80/lower.rs` routes CLIF instructions through the ISLE wrapper:

```rust
fn lower(&self, ctx: &mut Lower<Inst>, ir_inst: IRInst)
    -> Option<InstOutput> {
    isle::lower(ctx, self, ir_inst)
}
```

`lower.isle` declares instruction and branch constructors, but `lower/isle.rs`
still calls `todo!("constructor_lower")`.

## How

Wired instruction and branch lowering entry points and the initial ISLE lowering
context. The emitter (`inst/emit.rs`) gained a working NOP/HALT case and
little-endian 16-bit immediate encoding, and register-pair naming was corrected.

## Alternatives

The constructor calls remained placeholders, so this was an extensible template
rather than working code generation: it set the intended lowering interface
without compiling ordinary functions.
