## Files and implementation

`cranelift/codegen/src/isa/z80/lower.rs` routes CLIF instructions through the
ISLE wrapper:

```diff
+fn lower(&self, ctx: &mut Lower<Inst>, ir_inst: IRInst)
+    -> Option<InstOutput> {
+    isle::lower(ctx, self, ir_inst)
+}
```

`lower.isle` declares instruction and branch constructors, but `lower/isle.rs`
still calls `todo!("constructor_lower")`. The emitter gained a working NOP/HALT
case and little-endian 16-bit immediate encoding in `inst/emit.rs`. This set the
intended lowering interface without yet compiling ordinary functions.
