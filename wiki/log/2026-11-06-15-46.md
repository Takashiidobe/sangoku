# Move the host test suite and audit tools to Rust (sangoku-i72)

_2026-11-06 15:46_

Bookkeeping: tooling migration. The SM83 emulator, RGBDS harness, audits and
compiler checks were fourteen Python files in `tests/`; keeping them in Rust
puts everything under `cargo test` next to the compiler.

Removed all fourteen Python files. Shared emulator, RGBDS harness, audit
algorithms, compiler checks and baseline generation now live in the
`sangoku-test-support` crate under `tests/support`. Six explicit Cargo examples
expose `audit-runtime`, `audit-division`, `audit-popcount`, `check-spills`,
`check-popcount` and `generate-popcount-baselines`; flags and JSON/CSV reports
are unchanged. The root workspace includes the support crate and excludes the
three vendored compiler workspaces. Disabling automatic example discovery keeps
the target-only `blank.rs` out of host `cargo test`. No compiler/backend or
runtime assembly changes.

Ported all fifty test groups (exhaustive byte arithmetic, flags/timings,
register state, memory bounds, calls, traps, stack metrics) and added bank/path
rejection, invalid command input and historical random-sequence tests. The
MT19937/rejection sampler keeps the Python seed sequences, including 64-bit
seeds and checkpoints spanning multiple twists. 53 integration tests and the two
CLI tests pass.

Parity before deleting Python: seed-7 runtime/division/popcount reports and ROMs
match; all 49 ROM images byte-identical; both CSVs match byte for byte; the two
baseline generators produce byte-identical Rust and SDCC assembly. Legacy
sources and comparison artifacts stay under `build/python-tests-before` and
`build/rust-tests-port`. Full seed-0 Rust audits reproduce the three committed
CSVs: popcount 342928 executions, division candidates 309985, production
division 149329; compiler checks pass 171498 spill and 1918408 popcount
executions across six levels, 2892148 in total.

```text
cargo test
cargo run --example audit-popcount -- --samples 1024 --seed 0 --exhaustive16
cargo run --example audit-division -- --samples 1024 --seed 0 --exhaustive8
cargo run --example check-spills -- --exhaustive16
cargo run --example check-popcount -- --exhaustive16
```

(`audit-division` also takes `--variant runtime`.) `wiki/runtime-audits.md`
documents outputs and helper APIs. Clippy (also `--workspace --all-targets`),
`cargo fmt --all`, `cargo test`, `git diff --check` and the blank ROM link pass.
Tests require RGBDS, with SDCC only for baseline regeneration. Unrelated Beads
JSONL, fixture C formatting and vendored working-tree edits remain outside this
commit. Nothing was pushed.
