# Move the host test suite and audit tools to Rust

Completed sangoku-i72. Removed all fourteen Python files from tests. Shared
emulator, RGBDS harness, audit algorithms, compiler checks and baseline
generation now live in the sangoku-test-support crate under tests/support.
Runtime tests run with cargo test. Six explicit Cargo examples expose
audit-runtime, audit-division, audit-popcount, check-spills, check-popcount and
generate-popcount-baselines; their existing flags and JSON/CSV reports remain.

The root workspace includes the support crate and explicitly excludes the three
vendored compiler workspaces. Disabling automatic example discovery keeps the
target-only blank.rs out of host cargo test; the six tools remain registered
explicitly. No compiler/backend or runtime assembly changes were needed.

Ported the original fifty test groups, including exhaustive byte arithmetic,
flags/timings, register state, memory bounds, calls, traps and stack metrics.
Added bank/path rejection, invalid command input and historical random-sequence
tests. The MT19937/rejection sampler retains the Python seed sequences,
including 64-bit seeds and checkpoints spanning multiple twists. Fifty-three
integration tests and the two existing CLI tests pass with cargo test.

Before deleting Python, compared seed-7 runtime/division/popcount reports and
their retained ROMs. All measurements and inputs match; all 49 ROM images are
byte-identical. Both CSVs match byte for byte. Running the two baseline
generators at the same output path produces byte-identical Rust and SDCC
assembly. Legacy sources and comparison artifacts remain under
build/python-tests-before and build/rust-tests-port; active documentation now
uses the Rust commands.

Full seed-0 Rust audits reproduce the three committed CSV files byte for byte:
popcount 342928 executions, division candidates 309985, and production
division 149329. Rust compiler checks also pass 171498 spill executions and
1918408 popcount executions across all six optimization levels. These five runs
cover 2892148 executions, retaining exhaustive u16 and eight-bit pair checks.

Reproduce with cargo test; cargo run --example audit-popcount -- --samples 1024
--seed 0 --exhaustive16; cargo run --example audit-division -- --samples 1024
--seed 0 --exhaustive8 (also --variant runtime); cargo run --example
check-spills -- --exhaustive16; cargo run --example check-popcount --
--exhaustive16. wiki/runtime-audits.md documents outputs, retained artifacts and
helper APIs.

cargo clippy --allow-dirty --fix, cargo clippy --workspace --all-targets
--allow-dirty --fix, cargo fmt --all, cargo test and git diff --check pass.
cargo run -- build examples/blank.rs build/blank.gb links the smoke ROM using
the documented pinned backend build. Tests require RGBDS, with SDCC only for
baseline regeneration. Unrelated Beads JSONL, fixture C formatting and vendored
working-tree edits remain outside this commit. Nothing was pushed.
