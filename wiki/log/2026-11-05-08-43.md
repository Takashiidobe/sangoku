## Files and implementation

The commit moves `cranelift/codegen/src/isa/z80/` to
`cranelift/codegen/src/isa/lr35902/` and renames the feature and metadata to
`lr35902`. The triple still uses target-lexicon's `z80` architecture, while the
backend identifies the narrower Game Boy CPU.

```diff
-mod z80;
+mod lr35902;
...
-"z80" => z80::define(),
+"lr35902" => lr35902::define(),
```

The port also adapts the scaffold to current Cranelift interfaces. Most
instruction lowering remains unimplemented at this point.
