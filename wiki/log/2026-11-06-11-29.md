# Migrate audited unsigned division and remainder

Completed sangoku-88j from base e950de7. runtime/udiv16.asm now uses the compact
SDCC Z80-derived SM83 split core with independent argument unpacking for both
public entries. The core leaves quotient in BC and remainder in HL; public
results return low/high in A/B. Zero divisors reach RST $10. The combined entry
remains an audit fixture for sangoku-yz4.

Removed runtime/udiv16alt.asm; its frozen audit copy remains under
tests/fixtures. Retained original source provenance, copyright/license notice
and additional exception in runtime/NOTICE, with the complete GPL v2 text in
runtime/COPYING. No vendored compiler/backend source changes.

Added the runtime variant to audit_division.py and changed test_div16.py to
exercise public ABI entries, callers, scratch-state independence, write bounds,
stack restoration and zero divisors. Updated trap-frame accounting regression.
Production object bytes match the audited q/r-only object at the same link
address. Both entries together occupy 95 ROM bytes, including the 70-byte core.
There are no table or scratch RAM allocations. Normal peak stack is 6 bytes;
zero-divisor callers reach the vector at a peak of 8 bytes.

Validation commands: python -B -m unittest discover -s tests -v python -B
tests/audit_division.py --variant runtime --samples 1024 --seed 0 --exhaustive8
--output build/runtime-division/results.json --artifacts
build/runtime-division/artifacts --csv wiki/audits/division16-runtime.csv cargo
run -- build examples/blank.rs build/blank.gb

All 149329 production audit executions pass: 18245 ordinary cases, 12 zero
divisor caller cases, and 131072 executions covering all eight-bit pairs through
each public entry. All 42 unit tests pass, including a separate seed-2
public-entry corpus and register poison values. The ROM smoke build passes with
existing compiler warnings. Ruff checks/format, cargo test --bins, cargo clippy
--allow-dirty --fix, cargo fmt and git diff --check pass.

Narrow-divisor quotient/remainder body costs are 1084/1088 clocks; synthetic
memory-backed callers cost 1236/1240. Wide-random caller means are 1133.3/1137.3
(1024 cases, seed 0). Per-class statistics are in division16-runtime.csv; method
and runtime verification are in wiki/audits/division16.md. Retained sources,
objects, maps, symbols, ROMs and hashes are under build/runtime-division.
Measurements use the flat-memory emulator; trap handler execution is excluded.
