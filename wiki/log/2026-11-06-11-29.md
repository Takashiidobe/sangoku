# Migrate audited unsigned division and remainder (sangoku-88j)

_2026-11-06 11:29_

## Context

The audit (`sangoku-mt4.2`) found the shipped `udiv16`/`urem16` incorrect
(`udiv16(1,1)` = 256, `urem16` read uninitialized state) and a broken alternate
that did not link. Division is required by `core`, so correctness came first and
size second: this change (from base e950de7) installs the audited SDCC
Z80-derived SM83 core. Both entries together are 95 ROM bytes (was an incorrect
97), with no table or scratch RAM.

## Case

`a / b` and `a % b` on `u16`, via `runtime/udiv16.asm`.

## Currently emits

Old object: 97 bytes for both helpers, wrong results (see above); the alternate
`runtime/udiv16alt.asm` failed to link on its quotient-local `.divide` label.
Listing not recorded.

## Should emit

The compact split core: quotient in `BC`, remainder in `HL`; public results
return low/high in `A`/`B`. Both entries unpack arguments independently. Zero
divisors reach `RST $10`. The combined entry stays an audit fixture for
`sangoku-yz4`. Production object bytes match the audited q/r-only object at the
same link address; 95 bytes including the 70-byte core; normal peak stack 6
bytes, zero-divisor callers reach the vector at a peak of 8.

## How

- `runtime/udiv16.asm` rewritten; `runtime/udiv16alt.asm` removed (frozen audit
  copy stays under `tests/fixtures`).
- Source provenance, copyright/license notice and exception kept in
  `runtime/NOTICE`; full GPL v2 text in `runtime/COPYING`. No vendored
  compiler/backend changes.
- Runtime variant added to `audit_division.py`; `test_div16.py` now exercises
  public ABI entries, callers, scratch-state independence, write bounds, stack
  restoration and zero divisors. Trap-frame accounting regression updated.
- 149329 production audit executions pass: 18245 ordinary cases, 12 zero divisor
  caller cases, 131072 executions covering all eight-bit pairs through each
  public entry. All 42 unit tests pass, including a seed-2 public-entry corpus
  and register poison values. ROM smoke build passes with existing compiler
  warnings. Ruff, `cargo test --bins`, clippy, fmt, `git diff --check` pass.
- Narrow-divisor quotient/remainder body costs are 1084/1088 clocks; synthetic
  memory-backed callers 1236/1240. Wide-random caller means 1133.3/1137.3 (1024
  cases, seed 0). Statistics: `division16-runtime.csv`; method in
  `wiki/audits/division16.md`. Artifacts under `build/runtime-division`.

```text
python -B tests/audit_division.py --variant runtime --samples 1024 --seed 0 \
  --exhaustive8 --output build/runtime-division/results.json \
  --artifacts build/runtime-division/artifacts \
  --csv wiki/audits/division16-runtime.csv
cargo run -- build examples/blank.rs build/blank.gb
```

## Alternatives

Measurements use the flat-memory emulator; trap handler execution is excluded.
The combined divmod wrapper is deferred to `sangoku-yz4` (excluded until used).
