# Cranelift 80241cb8 — Lower I16 stack addresses

_2026-11-05 13:15:20_

## Files and implementation

`cranelift/codegen/src/isa/lr35902/lower.rs` handles `Opcode::StackAddr` with an
I16 result. It asks the ABI for the stack-slot offset, returns two byte
registers, and emits `StackAddr16`:

```diff
+let offset = ctx.abi().sized_stackslot_area_offset(stack_slot, offset)?;
+ctx.emit(Inst::StackAddr16 {
+    dst_low: *dst_low, dst_high: *dst_high,
+    mode: StackAMode::Slot(i64::from(offset)),
+});
```

`inst/emit.rs` forms the address with `ld hl, sp + offset`, which is the
LR35902's signed-displacement form; later loads/stores dereference HL bytewise.
This replaces a generic stack-address assumption that the target cannot execute
directly and was needed for rustc-generated spills and locals.

Commit: `80241cb8` — Cranelift (`third_party/wasmtime`). Purpose: Generate
addresses for local stack slots on a CPU whose ordinary loads do not accept
SP-relative addressing. Change: Added lowering for `stack_addr.i16` and
frame-relative stack access. Implementation: Materialize the stack address
through HL using LR35902 SP-plus-signed-offset instructions and bytewise
loads/stores; added corresponding ABI and emission support. Result: Stack locals
can be addressed without assuming native arbitrary-width memory operations.
