# Cranelift 80241cb8 — Lower I16 stack addresses

_2026-11-05 13:15:20_

## Context

rustc-generated spills and locals need the address of a stack slot as a 16-bit
pointer. The LR35902 cannot address memory relative to `SP` in ordinary loads
and stores; only `ld hl, sp + signed8` forms an address. Commit `80241cb8` in
Cranelift (`third_party/wasmtime`); no bead.

## Case

CLIF `stack_addr.i16` on a stack slot.

## Before

No lowering for `Opcode::StackAddr` with an `I16` result.

## After

```asm
ld hl, sp + <offset>
```

The result is fixed to `HL` (`dst_low` = `L`, `dst_high` = `H`); loads and
stores dereference it bytewise.

## How

`lower.rs` asks the ABI for the slot offset and emits `StackAddr16`:

```rust
let offset = ctx.abi().sized_stackslot_area_offset(stack_slot, offset)?;
ctx.emit(Inst::StackAddr16 {
    dst_low: *dst_low, dst_high: *dst_high,
    mode: StackAMode::Slot(i64::from(offset)),
});
```

`inst/emit.rs` and `inst/mod.rs` reuse `emit_stack_address` (the wide-offset
sequence of 0ff67e17) with the frame layout resolved at emission.
