# Audit frontend core epic with Rust fixtures (sangoku-57q)

_2026-11-07 18:27:32_

## Context

Epic `sangoku-57q` (LR35902 frontend and emission for core, P0) needed proof
that each Rust ABI pass mode, data relocation and dispatch form actually
survives CLIF generation, assembly, linking and the emulator, not only that
`core` lowers. `sangoku-57q.1` (z80 emission for every Rust ABI pass mode) asked
for scalar pairs, by-reference aggregates and `sret` to compile and run.

## Case

Rust sources under `tests/fixtures/clif/` covering ABI pass modes, string/array/
struct data relocations, `fn` pointers and `dyn Trait` dispatch, wide integers
and floats, runtime calls and core intrinsics.

## Before

Not recorded as separate fixtures; the audit surfaced two failures, f16
conversion symbols and u128 overflowing multiplication size.

## After

Generated CLIF snapshots for ABI pass modes, data relocations, indirect
dispatch, wide integers/floats, runtime calls, core intrinsics and an
optimization baseline, plus a MIR dump fixture. Nine ROM probes execute; two
regression checks preserve known build failures. Closed `sangoku-57q.1`, `.2`
and `.3` after verifying acceptance cases. Filed `sangoku-57q.4.1` (missing f16
conversion symbols) and `sangoku-57q.4.2` (u128 overflowing multiplication too
big). 150 nextest tests, clippy `--all-targets --allow-dirty --fix`, fmt, LSP,
diff checks and the hello ROM build pass.

## How

`tests/frontend_epic.rs` drives the fixtures (`abi-pass-modes.rs`,
`data-relocations.rs`, `indirect-dispatch.rs`, `wide-*.rs`, `runtime-calls.rs`,
`core-intrinsics.rs`, `frontend-optimization.rs`,
`tests/fixtures/mir/ frontend-debug.rs`). Coverage is documented in
`wiki/concepts/frontend-fixtures.md` and linked from the README. No backend
sources changed.

## Alternatives

Inventory, optimization, diagnostics and saved-phase tooling requirements of the
epic stay open.
