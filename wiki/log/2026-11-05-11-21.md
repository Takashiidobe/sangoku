# rustc_codegen_cranelift c60fe1b — Resolve call symbols in RGBDS output

_2026-11-05 11:21:25_

## Files and implementation

`third_party/rustc_codegen_cranelift/src/base.rs` reads imported function
declarations from the module, then `src/rgbds.rs` replaces Cranelift's
`User(...)` references with encoded linkage names:

```diff
+let symbol = module.declarations().get_function_decl(func_id).linkage_name(func_id);
+external_symbols.insert(format!("User({user_ref:?})"), symbol_name(&symbol));
...
+line.replace(external, symbol)
```

The encoder turns punctuation into `_HH` bytes so identifiers meet RGBDS syntax.
A two-codegen-unit test verifies that `call User(...)` becomes a call to the
exported symbol and that `rgblink` resolves it. Retaining debug names would
leave assembly references that are not declared linker symbols.

Commit: `c60fe1b` — `rustc_codegen_cranelift`. Purpose: Make calls between
separately emitted functions link by symbol name. Change: Replace Cranelift
`User(...)` references in assembly with RGBDS-compatible Rust symbol names.
Implementation: Read function declarations from the module, encode linkage
symbols as safe RGBDS identifiers, and rewrite references while printing each
function; added a multi-unit assemble/link test. Alternative: Leaving internal
`User(...)` debug names in output is not linkable; rewriting from module
declarations preserves the actual linkage name.
