# Shrink spill code and fallthrough jumps (sangoku-30k.9.1.9)

_2026-11-07 20:00:20_

## Context

Core code size is what stands between Rust and a 32 KiB ROM: at opt 0 `sort` was
23869 bytes and `heap` 93311. Every spill/reload of a register around a stack
slot was wrapped in saves of `HL` and `AF`, and every block ended in a `jp` even
when the target was the next block. Filed under `sangoku-30k.9.1.9`: spill save
elision (`.1`), fallthrough jumps (`.2`), a GBDK baseline (`.3`); `sangoku-4we`
reparented, duplicate `sangoku-9uf` superseded.

## Case

Any stack-slot access, and any block ending `jp .blockN` right before
`.blockN:`.

## Currently emits

```asm
push hl
push af
ld hl, sp + 6
ld a, [hl]
...
pop af
pop hl          ; 7-10 bytes per access
```

## Should emit

```asm
push hl
ld hl, sp + N+2
ld r, [hl]      ; or: ld [hl], r
pop hl          ; 5 bytes for B/C/D/E/A
```

No `AF` save: no LR35902 instruction reads flags set by an earlier one. H/L
loads save `A` only; H/L stores keep the `AF`+`HL` path. Dropping the
`push/pop hl` when `HL` is dead is still missing (below).

## How

Wasmtime lr35902 backend spill emission, and the RGBDS writer, which drops `jp`
to the next block and turns `jp cc,X` / `jp Y` / `X:` into `jp !cc,Y`. Linked
bytes (opt 0 / opt s):

- hello 8768 -> 7378 / 8131 -> 6866
- sort 23869 -> 19484 / 22550 -> 18316
- primes 30874 -> 25110 / 28284 -> 22894
- heap 93311 -> 74355 / 80365 -> 63682 (still over 32 KiB)

Tests: codegen unit 35/35, rgbds unit 7/7; `check-spills` passes 12096 access,
1024 pressure and compiled Rust probes (no longer requires `F` to survive).
Regenerated lower FileCheck fixtures (add16, load-store-i32, rust-call,
select-branch). nextest 156/165; the failures predate this change: uncommitted
heap work passes core/alloc externs to `no_core` fixtures (lowered x7, mir/clif
FileCheck) and link heap selection. `frontend_epic`
`unsigned_overflow_multiply64` failed once under load, then passed 4 times.

## Alternatives

Next: elide `push/pop hl` when `HL` is dead (needs liveness after register
allocation). fmt/clippy on the backend crates deferred to a later pass.
