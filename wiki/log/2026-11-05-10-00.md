# Cranelift dadb0685 — Format instructions as RGBDS assembly

_2026-11-05 10:00:20_

## Files and implementation

`cranelift/codegen/src/isa/lr35902/inst/mod.rs` replaces debug-style instruction
output with an RGBDS printer. For accumulator operations it renders the actual
moves needed around the CPU instruction:

```diff
+if regs::hw_enc(lhs) != a {
+    lines.push(format!("ld a, {}", asm_reg(lhs)));
+}
+lines.push(format!("{op} {}", asm_reg(rhs)));
+if regs::hw_enc(dst) != a {
+    lines.push(format!("ld {}, a", asm_reg(dst)));
+}
```

Tests check forms such as `ld a, b` / `add a, c` and stack loads/stores. This
printer is the readable assembly representation later consumed by the Rust
adapter and RGBDS, rather than a host disassembler.

Commit: `dadb0685` — Cranelift (`third_party/wasmtime`). Purpose: Produce
assembler-readable output for a Game Boy ROM toolchain. Change: Added RGBDS
textual formatting for LR35902 machine instructions. Implementation: Instruction
display emits RGBDS syntax and register names instead of relying on binary bytes
or a host disassembler. Design choice: Text assembly is the useful handoff
format for RGBDS; this lets the project inspect and assemble backend output
directly.
