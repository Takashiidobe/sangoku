## Files and implementation

`cranelift/frontend/src/frontend.rs` limits inline copy chunks to the target
pointer width before choosing an integer load/store type:


memcpy path. A U16-pointer test verifies a 24-byte copy uses twelve I16 loads
and stores and never emits I64. This prevents frontend-generated wide values
that the 16-bit address model cannot represent.
