# Phase 1: standalone Rust frontend with FileCheck fixtures

Issue sangoku-1uz. Adds `sangoku frontend <source.rs> [output.mir|-]`, which
runs the pinned rustc fork with `-Zunpretty=mir` and saves MIR (default
build/<name>.mir). It needs no codegen backend, so it avoids the LLVM
data-layout check that `--emit=mir` trips on for the lr35902 target. Paths are
remapped to `.` so output is machine independent. rustc setup is shared with
`build` via `rustc_command`.

Fixture types are subdirectories of tests/fixtures; `mir` is the first, with
return-const, add, branch and call. Expectations are `// CHECK` lines written
by `tools/update_filecheck.py` (follows nassau): regenerate with no arguments
or a glob, verify with `--check`. `cargo test --test filecheck` runs the check.
New phases add an entry to STAGES in the tool.

README: audit sections removed, testing condensed to the FileCheck workflow.
Audit code and wiki/audits are untouched. Requires FileCheck on PATH.
