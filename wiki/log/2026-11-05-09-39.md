## Files and implementation

`isa/lr35902/lower.rs` maps I8 `isub`, `band`, `bor`, and `bxor` to new machine
instructions. `inst/emit.rs` uses accumulator opcodes and models A as a clobber:

```diff
+Inst::Sub8 { dst, lhs, rhs } => emit_accumulator_op(sink, 0x90, dst, lhs, rhs),
+Inst::And8 { dst, lhs, rhs } => emit_accumulator_op(sink, 0xA0, dst, lhs, rhs),
+Inst::Xor8 { dst, lhs, rhs } => emit_accumulator_op(sink, 0xA8, dst, lhs, rhs),
+Inst::Or8  { dst, lhs, rhs } => emit_accumulator_op(sink, 0xB0, dst, lhs, rhs),
```

The shared helper copies the left operand to A when necessary, applies the
operation, then copies A to the result register. This matches the LR35902
instruction forms while exposing the temporary accumulator use to allocation.
