# Phase 3: LR35902 lowering from CLIF fixtures (sangoku-1b9)

_2026-11-06 18:30_

## Context

Phase 3 of the five-phase split (`sangoku-1b9`, P0): make lowering (CLIF,
register allocation, target instructions) runnable on saved CLIF alone, with
small fixtures that test it directly without rustc or RGBDS. This is what lets
us grow LR35902 op coverage quickly and check the code bytes each op costs.

## Case

`sangoku lower <input.clif> [output.s|-]`, backed by the workspace crate
`tools/lower` (`sangoku-lower`).

## Before

Lowering could only be exercised through a full rustc build; no direct way to
feed it CLIF.

## After

It parses CLIF with `cranelift-reader`, compiles each function with the lr35902
ISA taken from the file's `target`/`set` lines, and prints the VCode as RGBDS
assembly. Example fixture `shl16-const.clif` (`ishl` by 3), expected output:

```asm
ld a, b
ld b, c
sla a
rl b
sla a
rl b
sla a
rl b
ret
```

This is correct: the first two `ld` lines are the ABI (args in `B`,`C`, return
in `A`,`B`). Verified in the emulator by `audit-shifts` on 2026-11-06.

## How

- Formatting is the existing VCode rewriting from cg_clif's `src/rgbds.rs`,
  included by path so the two paths cannot drift; the libcall symbol table moved
  into `rgbds::runtime_libcalls` and is shared. Phase 4 replaces this
  formatting.
- Saved phase 2 files work as input: repeated headers are dropped and `u0:N`
  names resolve through `; symbol` comments. Hand-written fixtures use `%name`
  functions.
- Fixtures in `tests/fixtures/lower`: add16, call, select-branch, shl16-const,
  rust-call (saved `sangoku clif` output). Expectations are `; CHECK` lines from
  `tools/update_filecheck.py`.

## Alternatives

Phase 4 will replace the borrowed formatting.
