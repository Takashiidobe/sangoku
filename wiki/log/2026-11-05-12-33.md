## Files and implementation

`src/codegen_f16_f128.rs` now chooses the f128 compare helper's result type from
the target instead of a compile-time host constant:

```diff
+let cmp_result_ty = if matches!(fx.tcx.sess.target.arch, Arch::AArch64 | Arch::Arm64EC) {
+    types::I32
+} else {
+    fx.pointer_type
+};
```

The helper call and zero comparison both use `cmp_result_ty`; the old
`CMP_RESULT_TY` constant was removed from `src/compiler_builtins.rs`. The commit
fixes target-width assumptions while adjacent work decides to omit
floating-point routines for LR35902 rather than implement their arithmetic.
