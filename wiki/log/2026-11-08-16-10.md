# Bounded wider and widening multiplication integration

sangoku-mt4.7 and .1/.2: User explicitly requested implementation and Cranelift
wiring without an extensive audit. Keep existing low-32 wrapping kernels and
8-bit high/overflow behavior; add native signed/unsigned 16×16→32 products.

| Shape             | Size/speed linked bytes | Size/speed T-cycles, 0xffff×0xffff |
| ----------------- | ----------------------- | ---------------------------------- |
| unsigned 16×16→32 | 32/252                  | 1292/1072                          |
| signed 16×16→32   | 93/313                  | 1688/1468                          |

The unsigned kernel maintains multiplicand DE and product HL/BC, conditionally
adds then shifts through carry for 16 steps. Compact loops; speed unrolls all
steps and short-circuits either zero operand. A 61-byte signed wrapper shares that kernel and corrects the high half
by subtracting rhs when lhs is negative and lhs when rhs is negative. This
handles MIN and -1 without negating either input. No tables or scratch RAM.

ABI: lhs B/C, rhs A/[SP+2], full product A/B/C/D low-byte-first. Unsigned needs
no local stack; signed uses six frame bytes plus a nested two-byte return.
Both preserve SP and incoming arguments. All public registers/flags may be
clobbered. Cycles cover entry through RET, excluding outer caller costs.

Add GbcUmul16Wide/GbcSmul16Wide typed signatures and both symbol mappings.
Cranelift now uses them for 16-bit high-half/overflow and matching sign/zero-
extended i16 multiplication into i32. Known masked low limbs or logical shifts
exposing at most 16 bits can use unsigned widening. Mixed extensions safely
fall back to generic i32. Existing 32-bit high/overflow decomposition selects
new widening kernels for its partial products. No >32-bit helper is added.

Nine direct pairs include zeros in either position, 1×1, max×max, signed
MIN×-1, MIN×MIN, signed MAX×2 and asymmetric/carry patterns. Tiny no_core Rust
at 0/z checks full signed/unsigned/mixed products, live inputs and overflow.
CLIF checks six representative pairs at 8/16/32 for signed/unsigned high halves
and overflow value/flag pairs, plus full16 products. Explicit call checks prove
new paths are selected; stack arguments and non-stack writes are checked.

Validation: 19 targeted multiplication/linkage tests pass in 1.16 seconds;
The final three widening tests pass in 0.22 seconds after adding the speed
zero shortcut (unsigned 0×max takes 100 cycles). All 36 LR35902 backend tests
pass. Release backend and standalone CLIF tool rebuilt.
Clippy --allow-dirty --fix, fmt, LSP diagnostics and diff checks pass. No core,
Rust fork or application ROM rebuild and no broad SDCC/exhaustive audit.
Reproduce: cargo nextest run --no-fail-fast -E 'binary(widen_multiply)'.
