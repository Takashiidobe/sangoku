# Cranelift ecfc1aef — Print LR35902 jump labels

_2026-11-05 10:41:51_

## Context

The backend emits RGBDS assembly text from Cranelift's `PrettyPrint`. Jumps were
printed with `Debug` formatting of the label, which is not the label spelling
the assembly writer and the branch emitter agree on. Valid, readable branch
targets are required before any function with control flow can assemble. Commit
`ecfc1aef` in Cranelift (`third_party/wasmtime`); no bead.

## Case

Any `Inst::JumpKnown`, i.e. an unconditional `jp` to another block.

## Before

```rust
Inst::JumpKnown { dst } => format!("jp {dst:?}"),
```

## After

```rust
Inst::JumpKnown { dst } => format!("jp {}", dst.to_string()),
```

The `MachLabel` `Display` form is used, matching the emitted instruction and its
relocation. The change is in `cranelift/codegen/src/isa/lr35902/inst/mod.rs`.

## How

Label naming stays in the target printer so emitted instructions and their
destinations cannot choose different names. The companion RGBDS rewrite is
`a1b1e35` (log 2026-11-05-10-43).
